# 同业横向对比

快速对比同一行业几只股票的关键指标，一眼看出"谁的生意更好"。

## 用法

```bash
# 代码输入
python3 tools/peer_compare.py 601058 002984 000589 601500

# 中文名输入（自动转代码）
python3 tools/peer_compare.py 赛轮轮胎 森麒麟 贵州轮胎 三角轮胎 玲珑轮胎

# 混合输入
python3 tools/peer_compare.py 赛轮轮胎 002984 玲珑轮胎
```

## 输出指标

| 指标 | 含义 | 怎么看 |
|------|------|------|
| ROE | 资本效率 | 越高越好，>15%优秀 |
| 毛利率 | 定价权 | 越高越有护城河 |
| 净利率 | 最终赚钱能力 | 反映成本控制 |
| 营收(亿) | 规模 | 龙头vs跟随者 |
| 净利(亿) | 利润绝对值 | — |
| 3yCAGR% | 3年营收复合增速 | 成长性 |
| 负债% | 杠杆 | >65%需警惕 |
| PE/PB/市值 | 估值 | 东财API可用时显示 |

## 数据源

- **财务数据**：同花顺THS（稳定）—— `tools/ashare/provider`
- **估值数据**（PE/PB/市值）：东财spot（可能限频，失败时自动跳过只显示财务）

## 典型用法场景

| 场景 | 命令 |
|------|------|
| 轮胎板块 | `赛轮轮胎 森麒麟 贵州轮胎 三角轮胎 玲珑轮胎 通用股份` |
| 白酒板块 | `贵州茅台 五粮液 泸州老窖 山西汾酒 今世缘` |
| 医美板块 | `爱美客 华熙生物 昊海生科` |
| 化妆品 | `珀莱雅 贝泰妮 丸美生物 上海家化` |
| 电解液 | `天赐材料 新宙邦 江苏国泰` |

## 工作流

1. 解析输入（代码直接用，中文名用 `stock_info_a_code_name` 模糊匹配转代码）
2. 逐只用THS拉5年财务，计算最新指标+3年CAGR
3. 尝试东财拉PE/PB/市值（失败则跳过）
4. 输出对比表

## 局限

1. **只做初筛对比**，不替代深度研究。看出"谁的数字好"后，仍需用 `/investment-research` 深研
2. **不含商业模式判断**：数字好≠生意好（参考海南华铁OCF/NI陷阱）
3. **东财限频时无估值**：只能看财务指标，PE/PB需API恢复后补
4. **周期股慎用单年数据**：周期底部/顶部的单年ROE会失真，建议看多年

## 对比后的判断框架

拿到对比表后，按这个顺序看：
1. **谁的ROE+毛利率双高** → 生意质量最好的候选
2. **谁的3yCAGR最高** → 成长性最好（但要看是否可持续）
3. **谁的负债率最低** → 财务最安全
4. **规模(营收)最大的是不是也最赚钱** → 检验规模效应是否真实
5. 综合选出2-3只 → 再用 `/investment-research` 逐一深研
