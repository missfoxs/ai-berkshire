## 核心结论

**综合评分：★★★☆（3.5/5）——优秀的公司，合理的价格，但不在正确的位置（铝周期偏高位）**

中国宏桥是全球成本最低的电解铝生产商（吨铝成本13,034元），张波接班6年交出营收翻倍+去杠杆+拥抱绿电的漂亮答卷。但HKD 24.18（PE 9.8x）买的是"铝价高位+利润巅峰"的定价。**PE 9.8x看起来便宜，但周期股的PE在利润顶峰最便宜时恰恰是最危险的时候。** 等待铝价回调至17,000-18,000元（全行业亏损宏桥仍盈利）、PE被动升至15-20x时——那才是周期股的正确买点。

**投资建议**：稳健型投资者**等待铝价回调**。积极型投资者可**持有收息（6.8%股息率）但不加仓**。保守型投资者**回避**周期股。
