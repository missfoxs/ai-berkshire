## 核心结论

**综合评分：★★★（3/5）——品牌心智垄断但品类天花板明显，管理层诚信问题是最大"红旗"**

- **商业模式（★★★）**："RIO=预调酒"心智垄断，毛利率69%。但复购率低、无定价权、品类天花板85亿
- **财务（★★★）**：OCF/NP=1.38现金流向好，但ROE从20%→13%、存货涨至13.76亿
- **行业（★★★）**：日本RTD成功不必然在中国复制。真正对手是精酿啤酒、新式茶饮
- **管理层（★★）**：刘晓东留置87天是致命诚信污点。威士忌豪赌IRR仅9%、回收期12年

**投资建议**：稳健型投资者**回避**。激进型可在16-18元小仓博弈（PB接近历史底部3.6x），但明确这是"赌威士忌期权+管理层清白"，不是价值投资。
