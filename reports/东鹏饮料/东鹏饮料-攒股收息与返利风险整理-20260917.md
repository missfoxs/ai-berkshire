> 整理日期：2026年9月17日

## 一、30 秒看懂这门生意

| 维度 | 一句话 |
|------|--------|
| **卖什么** | 功能饮料（提神），主力大单品「东鹏特饮」500ml 金瓶 |
| **卖给谁** | 蓝领：货车司机、建筑工人、外卖骑手——价格敏感、高频复购 |
| **怎么赢** | 便宜（约 5 元/500ml）+ 到处能买（450 万终端）+ 「累了困了」心智 |
| **靠什么赚钱** | 规模效应，不是品牌溢价——ROE 高来自周转和渠道，不是茅台式定价权 |
| **第二曲线** | 补水啦（电解质水）、东鹏大咖（即饮咖啡）等，复用现有渠道 |

**飞轮**：低价大瓶 → 蓝领爱买 → 销量大 → 成本更低 → 经销商赚得多（毛利约 50%）→ 更愿意铺货 → 终端更多 → 销量更大……

## 二、行业黑话速查

| 术语 | 通俗解释 |
|------|---------|
| **PET 瓶** | 塑料瓶装，成本低于红牛铁罐，支撑低价 |
| **终端网点** | 实际售卖点：小卖部、加油站、网吧、工地店 |
| **经销商** | 批发商，从工厂拿货再分销到各地终端 |
| **动销** | 终端真实卖出，不是堆在经销商仓库 |
| **合同负债** | 预收款 + 尚未兑现的销售返利等，反映渠道关系 |
| **销售返利** | 给经销商/终端的促销折扣，承诺了但还没用货或现金兑现 |
| **冰冻化** | 在店里投放冰柜，冷饮更好卖，冰柜也占住货架 |
| **五码合一** | 瓶盖/箱上多码追踪，防窜货 + 扫码营销 |
| **一元乐享** | 扫码中奖后加 1 元换购，促复购 |
| **华彬红牛 / 天丝红牛** | 中国「红牛」商标纠纷双方，内斗 10 年给东鹏留窗口 |
| **先款后货** | 经销商先付钱再拿货，公司现金流好、应收极低 |

## 四、「刚哥爱投资」文章核心观点整理

### 4.1 大家在问什么

> 东鹏增速约 20%、PE 约 15 倍、股息率 3%+，食品饮料里很吸引人——**适不适合攒股收息？为什么还跌？**

### 4.2 市场担心的两件事（利空）

#### ① 合同负债 + 销售返利异常

| 项目 | 数据/现象 |
|------|----------|
| 合同负债总额 | 50 多亿 |
| 其中销售返利 | 30 多亿 |
| 占营收比例 | 约 16%（行业普遍 10% 以下） |
| 趋势 | 近两年增长很快 |

**逻辑链**：

```
高返利 → 刺激经销商多进货、多铺货
       → 返利将来要用货或现金兑现
       → 若集中兑现：要发出大量货 → 增加生产成本 → 冲击净利润
       → 若动销放缓、返利力度不得不降 → 渠道推力减弱 → 大单品销售受影响
```

**市场比喻**：像给自己加了杠杆——返利能一直玩就还能撑；渠道饱和、动销不行时，杠杆会反噬。

**仓库交叉验证**（2026Q1）：
- 应付销售返利 34.48 亿，同比 +70%
- 相当于 2025 全年净利润的约 78%
- 合同负债约 49 亿（年末约 60 亿）

#### ② 大单品增速换挡

| 信号 | 数据 |
|------|------|
| 东鹏特饮市占率 | 销量 51.6%，销售额 38.3%——再高增长难 |
| 特饮增速 | 2025 +17% → 2026Q1 +13% |
| 广东大本营 | 2026Q1 仅 +3%，几乎零增长 |
| 补水啦 | 2025 +119% → 2026Q1 +13%，第二曲线降速 |
| 竞争 | 外星人、农夫山泉等围猎电解质水 |

**逻辑链**：

```
大单品接近饱和 → 经销商减少铺货意愿
              → 返利集中兑现冲击利润
              → 净利润下降 → PE 从 15 倍「被动变贵」→ 股价承压
```

### 4.3 作者认可的一面（利多）

**过去 5 年（2021–2025）现金流账**：

| 项目 | 金额 | 说明 |
|------|------|------|
| 经营现金流 | 193 亿 | 比净利润 124 亿多 70 亿——占用上下游资金 |
| 资本开支 | 62 亿 | 建工厂扩产能（6 亿→22 亿/年） |
| 自由现金流 | 约 121 亿 | 193 − 62 |
| 分红 + 回购 | 79 亿 | 股东回报 |
| 存下来 | 约 42 亿 | 现金从十几亿涨到 100 亿+ |

**结论**：完全靠内生增长——扩产能、高分红、还存了大笔钱。净利润 11 亿→44 亿（约 4 倍），企业本身很强。

### 4.4 为什么「企业成长 4 倍，股东还赚不到钱」

| 时点 | 估值 |
|------|------|
| 5 年前 | PE 约 100 倍（买太贵） |
| 现在 | PE 约 15 倍（估值回归） |

**教训**：再快的成长，买在 100 倍 PE，五年也可能不赚钱。

### 4.5 作者最终立场

- **短期**：市场定价「返利风险 + 增速换挡」，股价承压合理
- **长期**：即使不再增长，仍可能是高股息价值股
- **估值方法**：按「**如果不增长了，值多少钱**」来估，不按「永远 20% 增长」来估
- **动作**：暂时列入「优秀高股息企业」观察表

## 六、攒股收息：怎么判断

### 6.1 适合收息的逻辑

- 即使零增长，21% 净利率 + 80% 分红规划 → 股息率有支撑
- 5 年 FCF 121 亿，分红 79 亿后仍有余钱
- 渠道壁垒深，不是随时会倒闭的生意

### 6.2 不适合当「高成长博傻」的逻辑

- 定价权弱（建立在「便宜」之上）
- 大单品占比 75%，增速换挡
- 返利机制像杠杆，不能假设永远维持

### 6.3 建议的估值框架

```
第一步：假设增速降到 5–10% 或零增长
第二步：算 steady-state 净利润 × 合理 PE（15–20x）
第三步：加上股息率是否 ≥ 3–4% 作为安全边际
第四步：单独跟踪「应付销售返利 / 合同负债」占营收比例是否继续攀升
```

### 6.4 关键跟踪指标（每季看）

| 指标 | 健康信号 | 警示信号 |
|------|---------|---------|
| 应付销售返利余额 | 增速 ≤ 营收增速 | 增速远超营收（如 +70% vs +21%） |
| 返利占营收比 | 维持或略降 | 从 16% 继续攀升 |
| 东鹏特饮增速 | ≥15% | <10% |
| 合同负债（年末） | 季节性波动正常 | 异常堆积不消化 |
| 广东区域增速 | 低个位数可接受 | 转负 |
| 经营现金流/净利润 | >1.0 | <0.8 持续 |

## 九、一句话结论

**东鹏是渠道驱动、现金流极好的快消龙头，但市场担心它用高返利换增长、大单品接近饱和；股价跌是「预期下修 + 估值回归」，不是生意突然变坏。攒股收息可以观察，但估值要按增速下来以后算，并每季跟踪返利余额。**
