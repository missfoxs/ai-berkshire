# 神火股份（000933.SZ）产业链投资研究报告

**报告日期：2026-08-06 | 研究方法：四大师分析框架（巴菲特/芒格/段永平/李录）**

---

## 摘要（结论先行）

1. **逻辑链高度确定且正在加速兑现**：电解铝4500万吨产能天花板已近（当前~4300万吨，仅剩~200万吨空间）→ 供给增长被政策"锁死" → 需求端新能源车+光伏+数据中心接棒房地产 → 供需缺口扩大 → 铝价中枢持续抬升（LME $3,241/吨，年涨+24%，库存降至本世纪最低）→ 低成本产能利润暴增。这是**供给侧改革红利**的教科书式案例。

2. **神火股份是"煤电铝一体化"的极致受益者**：新疆基地自备电厂电价0.15-0.25元/kWh（行业平均0.35-0.45元），仅电费一项每吨铝节省1500-2700元。2026H1净利润60.78亿（同比+170%），铝价上涨几乎全部转化为利润增厚——这是典型的低成本生产者在涨价周期中的"利润杠杆效应"。

3. **估值极便宜**：当前PE约8-9倍（按2026年全年利润120亿+估算），PB约1.96倍，股息率~2%。相比中国宏桥（港股，PE 6-7倍）和云铝股份（PE 12-15倍），神火估值处于合理偏低区间。

4. **但这本质是一门周期性生意**：铝价可以涨到$3,241/吨，也可以跌回$2,000/吨。煤炭+电解铝双周期叠加，波动性大于纯铝企业。河南煤矿安全事故风险、氧化铝价格飙升对利润的侵蚀、以及"永城市国资"作为实控人的治理质量——都是需要关注的风险。

5. **操作结论**：**★★★★（卫星仓位候选）**。当前是电解铝行业供需格局最好的历史时期之一（供给锁死+库存极低+需求结构升级），神火作为成本曲线最左端的玩家，享受最大的利润弹性。PE 8-9倍的周期股在行业高景气期不算贵——但要记住周期股"低PE=高风险"的反直觉规律。建议：可以配置，但仓位上限8-10%，铝价跌破$2,800/吨或PE升至15倍以上时减仓。

# 第一部分：投资逻辑链验证

## 逻辑链结构

```
电解铝4500万吨产能天花板政策（2017年供给侧改革）

        → 新增产能极其有限，行业格局从"增量竞争"转为"存量优化"
            → 需求端：新能源车用铝+光伏边框+数据中心散热 接棒 房地产下滑
                → 供需缺口逐年扩大，铝价中枢抬升
                    → 成本曲线最左端的玩家（煤电铝一体化）利润暴增
                        → 神火股份：新疆基地+自备电厂=最低成本
```

|------|---------|---------|---------|

| 低成本受益 | 神火成本优势 | ✅已验证 | 2026H1净利60.78亿（同比+170%），利润弹性远超铝价涨幅 |

## 已发生的验证事件

1. **铝价创近年新高**：LME铝价$3,241/吨，年涨+24%，12个月预测$3,421（Trading Economics）
2. **LME库存降至本世纪最低**：供需偏紧的最直接证据（Trading Economics确认）
3. **全球非中国产出下降**：2026年7月中国以外铝产量同比-6.7%，中东冶炼厂降开工率
4. **神火2026H1利润暴增**：净利润60.78亿元，较2025H1的22.50亿增长170%
5. **中国运行产能逼近天花板**：距4500万吨仅剩~200万吨空间，政策无松动迹象
6. **氧化铝价格2024年飙升**：全球供给短缺，推高铝生产成本——但低成本企业（自备电厂）受冲击最小

## 反例与风险信号

1. **铝价已涨24%——"好消息"是否已在股价中？** 神火股价23.43元，当日跌6.28%，可能开始计价见顶风险
2. **氧化铝价格飙升侵蚀利润**：占成本30-35%，如果氧化铝持续上涨，低电价优势部分被抵消
3. **房地产需求拖累**：建筑用铝占比~30%，中国房地产下行尚未结束
4. **全球衰退风险**：如果全球经济衰退→工业金属需求全面下滑→铝价暴跌
5. **煤矿安全事故**：2025年5月山西矿难后大范围安全检查，神火河南煤矿面临同类风险（停产→产量下降）

# 第四部分：神火股份四大师深度分析

## 生意本质（段永平）

**一句话**：河南国企，靠新疆低电价冶炼电解铝，同时经营河南煤矿——本质是"低成本资源型制造商"。

**追问：这是一门好生意吗？**

有条件的好生意。"好"在于：①4500万吨天花板=政策赋予的"准入壁垒"；②新疆自备电厂电价0.15-0.25元/kWh，相当于拥有了一张"永久低成本牌照"；③铝价上涨时利润弹性极大（2026H1利润+170%，而铝价仅涨24%）。"不好"在于：①这终究是周期股，铝价跌回$2,000时利润可能腰斩；②煤矿安全风险是黑天鹅；③国企治理——永城市国资作为实控人，决策效率和股东回报可能不如民营企业。

大概率在。4500万吨天花板是政策红线，短期不会放松（碳中和方向一致）。自备电厂+新疆煤炭资源也不会消失。风险点：如果10年后碳中和政策要求电解铝全部使用绿电，自备火电的成本优势可能被"碳税"侵蚀——但这至少是5-10年后的事。

## 风险（芒格）

### 最可能的失败方式

1. **铝价暴跌**：全球经济衰退→工业金属需求崩溃→铝价跌回$2,000/吨→利润腰斩
2. **氧化铝价格持续飙升**：挤压冶炼利润（占成本30-35%），抵消低电价优势
3. **煤矿重大安全事故**：停产+罚款+负面舆论→短期业绩暴跌+长期声誉受损
4. **国企治理问题**：永城市国资可能优先保就业/税收而非股东回报

### 最坏情景下值多少

- 假设铝价跌至$2,200/吨（2020年水平），煤价同步下跌
- 利润可能降至20-25亿/年（2020年水平约15亿）
- 对应PE 15倍 = 市值300-375亿 = 股价13-17元（当前23元的-28%至-43%）
- PB 1倍兜底 = 净资产11.96元×22.49亿股 = 269亿 = 股价~12元

### 聪明人为什么不买

- "低PE=高风险"：周期股PE最低时往往是利润顶部，后面是利润下滑
- 国企治理折价：分红率不高（2025年度每10股5元，股息率仅2.1%）
- 大宗商品无定价权：完全看天吃饭（铝价/煤价）
- 铝价已涨24%：可能已是右侧交易的尾声

| 利润 | 行业利润从亏损到暴利 | 行业利润从微利到超额利润 |
| 赢家 | 低成本+产能大的龙头（中国神华/陕西煤业） | 低成本+产能大的龙头（宏桥/神火） |
| 投资者回报 | 龙头股涨3-5倍 | 神火从5元涨到30元+（6倍） |

**启示**：供给侧改革的投资逻辑=买低成本龙头+长持=赚大钱。但要注意：煤炭股2021-2022年涨完后进入了高位震荡，周期股不是"永远涨"的。

## 偏误自查

- **叙事偏差**："供给天花板+需求增长=铝价永远涨"——过于完美的故事。现实中全球衰退可以瞬间打破这个逻辑。
- **锚定效应**：不应被2026H1利润+170%锚定——这是周期高点的特征，不是"常态"。
- **从众效应**：铝价年涨24%、神火H1利润暴增——市场热度正高，可能已是中后期。

# 第六部分：文明趋势判断（李录框架）

## 底层趋势定性

**电解铝不是"文明级范式转移"，而是"存量经济中的结构性受益者"。**

铝本身是成熟材料（100年+历史），不会被颠覆。但在能源转型中，铝的角色被重新强化：新能源车轻量化、光伏支架/边框、风电塔筒、储能壳体——这些新兴需求在**替代传统房地产需求**。

这意味着：铝的总需求不会爆发性增长（不像储能/AI），但会保持稳健增长（2-4%/年）；而供给被锁死，价格中枢持续抬升。

## 10-20年终局

1. **产能天花板不会放松**（碳中和+环保方向一致），供给增长趋零
2. **需求结构完成切换**：建筑从30%降至15%，交通+能源从40%升至55%
3. **绿色铝溢价形成**：欧洲CBAM碳边境税→使用水电/核电的铝有溢价→云铝/水电铝受益
4. **再生铝占比提升**：从目前20%升至30-40%，一定程度压制原铝需求增长

## 赢家通吃环节

电解铝冶炼——因为产能指标+低电价=不可复制的竞争优势，强者恒强。

## 最可能被颠覆的环节

铝加工（板/带/箔）——壁垒低、充分竞争、可能被新材料（碳纤维/高强钢）在部分场景替代。

## 四位大师模拟点评

> **巴菲特**：我喜欢产能天花板这个概念——这等于政府帮你建了一条护城河。神火的新疆基地让它坐在成本曲线最左端，铝价涨它赚最多，铝价跌它也最后一个亏。但我不喜欢两点：第一，大宗商品企业没有定价权，你永远不知道明年铝价是多少；第二，这是个国企，它没有义务把利润全还给你——看看分红率就知道了。如果管理层像中国神华那样大幅提高分红，我会更有兴趣。

> **芒格**：反过来想——铝价能涨到$3,241，就一定能跌回$2,000。2008年铝价从$3,300跌到$1,300，花了6个月。当前PE 8-9倍看着便宜？周期股低PE往往意味着利润顶——当PE涨到20倍的时候，才是真正便宜，因为那时利润在底部。我的建议：如果要买，仓位控制好，永远不要因为"PE低"就觉得安全。

> **段永平**：新疆布局是正确的战略——这说明管理层至少做了一次"对的事"。煤电铝一体化的模式也说得通。但我有两个担心：第一，永城市国资作为实控人，管理层的激励是什么？他们是在为股东创造价值还是在为地方政府交差？第二，这门生意的核心是"成本低"——但成本低不等于"好生意"。真正的好生意是有定价权的——比如茅台可以年年提价，但铝厂永远不能。

> **李录**：电解铝不是我会重仓的赛道——它不具备"10年10倍"的基因。但作为组合中的配角，它有独特价值：①供给侧改革创造了类垄断格局；②新能源车+光伏提供了结构性需求增量；③极低估值提供了安全边际。如果我配置，我会把它当作"现金牛"而非"成长股"——每年赚周期利润，耐心等高分红政策。真正让我兴奋的是另一个问题：如果全球碳关税全面落地，中国火电铝是否会面临出口惩罚？如果是，云铝这种水电铝反而有更大的长期价值。
