## 四位大师核心结论汇总（详见各分报告）

### 一、段永平视角：商业模式 ★★★★★
- 全球 33% 市占率（= 2-10 名总和）+ 浮法自供 95%
- 海外占比 50%+ 持续提升 + 综合成本比同行低 25-30%
- 双重护城河：全球产业链卡位者 + 垂直一体化寡头
- ASP 五年 CAGR 7.34%（174→248 元/㎡）

### 二、巴菲特视角：财务估值 ★★★★☆
- 9/10 项硬指标全过（ROE 23.55%、OCF/NI 1.16-1.30、派息率 45%）
- 当前 PE 15.9x = 5 年 28.6% 分位，处于"合理偏低"区间
- 三情景估值：乐观 ¥135.7 (+139%) / 中性 ¥92.7 (+63%) / 悲观 ¥57.9 (+2%)
- 扣非隐含 PE 13.35x（剔除汇兑）

### 三、芒格视角：行业竞争 ★★★★☆
- 福耀全球 30% 市占率（行业第一）
- 毛利率领先海外三巨头 17pp（38.3% vs 22-25%）
- 国内 CR3 > 80%，绝对垄断格局
- 智能化玻璃（智能天幕/HUD/调光）= 第二曲线

### 四、李录视角：风险管理 ★★★★☆
- 创始人曹德旺 79 岁主动交班，留任"终身荣誉董事长"
- 曹晖 55 岁接任（1989 加入，35 年工龄），最了解海外业务
- 60% 分红率 + 50% 海外收入 + 垂直整合 = 强反脆弱性
- 主要风险：美国 232 关税 + 汇率波动 + SAM 整合

### 综合评分：★★★★☆（4.5/5）
