# 宇通客车（600066.SH）投资研究报告

**日期**：2026年8月19日
**研究框架**：四角色并行分析（段永平/巴菲特/芒格/李录）
**信息丰富度评级**：A级（上市多年，客车龙头，覆盖充分）

---

## 一句话结论

宇通客车是"坏行业里的龙头公司"——国内客车是衰退中的存量市场（公交电动化87.5%渗透率已完成、高铁挤压长途），但宇通在国内占据31%份额（超第2-4名之和），并成功把能力复制到海外（海外收入占比51%首超国内、毛利率29.6%是国内19.1%的1.5倍、量价齐升）。财务质量极高（零有息负债、净现金近百亿、分红率99.66%、股息率8.38%）。**但2026Q1已出现拐点（净利-12.69%），38%的ROE是周期高点而非稳态，且治理历史有MBO硬伤、72岁实控人接班未解。四份报告一致给3-4星——这是一只"高分红+真实护城河"的优质制造龙头，适合作为高股息配置仓，但不是"闭眼拿十年"的复利机器，当前PE 12x不贵但需盯周期拐点。**

## 各维度分析摘要

### 商业模式（段永平）★★★★
1. 本质是"有定价权的制造业"，不是消费品——B2B项目制，每次招标重新竞争
2. 海外差异化真实：全栈自研三电+数据闭环（51.3万台车辆日均52亿条数据）+场景定制
3. 海外定价权强（对标奔驰定价、净利率13.6%是同行3-7倍），但国内仍是价格战
4. 护城河是"需要持续挖的"（靠4%+营收研发维持），不是"天生就有的"
5. 段永平定论："优秀的制造业，但不是茅台苹果那种'傻瓜都能经营、十年不卖'的生意。"

### 财务与估值（巴菲特）★★★★
1. ✅ 零有息负债、净现金近百亿、5年累计OCF/NI=1.48x、分红率99.66%、股息率8.38%
2. 🔴 2026Q1净利-12.69%、营收-7.92%，高增长出现拐点
3. 🔴 2025单年OCF/NI仅0.58（应收53.8亿+存货35.4亿扩张），现金流质量时点性恶化
4. 三情景：乐观57.3元(+92%)/中性37.9元(+27%)/悲观17.2元(-42%)，未含8%股息
5. 巴菲特："38%的ROE是周期给的，不是永久给的。要问海外护城河能否扛住国内需求下滑。"

### 行业与竞争（芒格）★★★
1. ✅ 分化行业：国内夕阳存量（公交电动化87.5%渗透率完成），海外成长蓝海（出口+30%+）
2. ✅ 国内31%份额超第2-4名之和，寡头龙头；出口毛利率29.6%是国内1.5倍，量价齐升
3. ⚠️ 比亚迪是海外最大对手（份额24% vs 宇通22.7%，但宇通增速更快+高端化）
4. 芒格定论："不要因为行业平庸就错过在平庸行业里占据垄断位置、且正在升级到高毛利海外市场的龙头。但它所在的基本盘正在变老。"

### 风险与管理层（李录）★★★
1. 🔴 治理历史有硬伤：2001-2004年MBO"假道司法拍卖"绕开监管，汤玉祥曾被证监会处罚；2014年42.6亿收购精益达被质疑利益输送
2. 🔴 72岁实控人汤玉祥接班未解，这是"买股票就是买管理层"框架下的头号不确定项
3. ✅ 现金流大幅改善：2026H1现金流暴增247%、应收大降44%、分红率99.65%
4. 李录定论："好公司+普通行业，从周期博弈向文明级趋势迁徙中，非十年重仓级标的。"

## 投资论点（Bull vs Bear）

### 🟢 看多逻辑
1. 海外出口量价齐升（销量+22%、收入+39%、ASP+13%），毛利率29.6%是国内1.5倍
2. 全球电动化+中国制造出海是真实长周期，宇通海外市占率欧洲第一（15.5%）
3. 零有息负债+净现金近百亿+分红率99.66%+股息率8.38%，A股顶级股东回报
4. 国内31%寡头份额+海外400+服务网点，规模与渠道壁垒真实
5. L4自动驾驶客车（24城市交付200辆+600万公里）是未来期权
6. 全栈自研三电+数据闭环，技术壁垒国内客车行业最高

### 🔴 看空逻辑
1. 国内客车是衰退存量市场（公交电动化完成+高铁挤压+旅游大转小），需求长期下移
2. 2026Q1净利-12.69%、营收-7.92%，高增长拐点已现
3. 2025单年OCF/NI仅0.58，应收53.8亿+存货35.4亿扩张，现金流质量时点性恶化
4. 治理历史有MBO硬伤+72岁实控人接班未解
5. 比亚迪海外紧追（份额24% vs 22.7%），且有电池垂直整合优势
6. 欧洲"去风险"政治压力（数据安全+本地化要求）是出海悬顶之剑
7. 38%的ROE是周期高点，不是稳态，PB 4.23x不便宜

## 总结段落

宇通客车是研究池中"高分红优质制造龙头"的代表——它和赛轮轮胎（轮胎出海）、春风动力（摩托出海）同属"中国制造出海"逻辑，但宇通的财务质量更极致（零负债+分红99.66%+股息率8.38%）。四个角色的判断罕见地一致：**这是一家"好公司+普通行业"的结合体。** 它的护城河真实（海外技术+数据+服务组合壁垒，欧洲市占率第一），它的现金流真实（5年累计OCF/NI=1.48x），它的股东回报真实（分红率99.66%）。但它也背着三个真实的包袱：国内基本盘是衰退的存量市场、治理历史有MBO硬伤、72岁实控人接班未解。**当前PE 12x不贵，8.38%股息率提供了厚厚的下行保护，但2026Q1的利润拐点（-12.69%）提醒我们：38%的ROE是周期给的，不是永久给的。** 它不是"闭眼拿十年"的复利机器，而是一只"高股息+真实护城河"的周期成长股——适合作为组合里的防守型配置仓（吃股息+赌海外），但不适合作为核心重仓。真正的安全边际，在股价回到25元以下（PE<10x、股息率>10%）时才会出现。
