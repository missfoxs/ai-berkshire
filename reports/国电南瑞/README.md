## 核心结论

**综合评分：★★★☆（3.5/5）——优秀但不够伟大的公司，合理但不够便宜的价格**

- **商业模式（★★★☆）**：准垄断型系统集成商。护城河极深但不是"伟大生意"
- **财务（★★★★）**：ROE 16%+、OCF/NP 1.54、净现金235亿。盈利质量极其优秀
- **行业（★★★★）**：调度市占75-85%、直流控保近乎独占。"十五五"国网4万亿
- **管理层（★★★）**：业务优秀、治理平庸。央企任命制+甲方即大股东

**投资建议**：稳健型投资者可小仓分批在23-25元建仓（3年基准回报+26%、年化+8%）。保守型投资者等待PE 20x以下（约20-21元）。
