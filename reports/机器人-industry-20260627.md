> **数据截止**：2026年7月（部分财务为2025年报/2026Q1）
> **研究框架**：产业链全景扫描（/industry-research Skill）

## 一、投资逻辑链

### 1.1 底层趋势驱动

```
AI大模型突破（GPT/Gemini/GROOT） 
  → 机器人从"自动化设备"进化为"具身智能"
  → 感知-推理-执行闭环打通

人口老龄化 + 劳动力短缺
  → 中国60岁以上人口超3亿（2025）
  → 制造业工人年均减少300万+
  → 机器人密度已超德国（中国392台/万人 vs 德国371）

中国制造业升级
  → 工业机器人国产化率突破56%（2025）
  → 首次成为工业机器人净出口国
  → 人形机器人写入政府工作报告（连续2年）
```

### 1.2 完整逻辑链：趋势 → 刚需 → 受益环节

```
[趋势层]          AI大模型突破      人口老龄化        制造业升级
                     ↓                ↓                ↓
[需求层]      具身智能成为可能   劳动力替代刚需   自动化率提升诉求
                     ↓                ↓                ↓
[刚需确认]    特斯拉/Figure量产  中国机器人密度↑  国产替代政策推动
                     ↓                ↓                ↓
[验证事件]    见表1.3               ←——→              ←——→
                     ↓                ↓                ↓
[受益环节]  核心零部件（减速器/  工业机器人本体/   系统集成/行业
             丝杠/传感器/电机）    人形机器人整机    应用方案
```

## 三、各环节详细标注

### 3.1 减速器（谐波/RV/行星）

| 维度 | 谐波减速器 | RV减速器 | 行星减速器 |
|------|-----------|---------|-----------|
| **商业模式** | 卖设备（标准化产品，批量供货） | 卖设备 | 卖设备 |
| **毛利率区间** | 35-50%（绿的谐波约37%） | 25-35% | 20-30% |
| **竞争格局** | 国产化率72%+；绿的谐波国内市占60%+，全球第二；日企哈默纳科仍为技术标杆 | 国产化率约30%；纳博特斯克全球市占53%；双环传动国内第一 | 较分散 |
| **壁垒类型** | 精密加工工艺+材料热处理+专利 | 齿轮加工+摆线针轮设计+精密装配 | 中等 |
| **中国市场空间** | 2026年约47亿元（含工业+人形） | 2026年约39.58%份额 | 份额升至22.92% |
| **全球市场空间** | 2025年全球约32亿美元 | 同左 | 同左 |
| **卡脖子程度** | ★★★★ 国产已突破，高端仍有差距 | ★★★★★ 日系仍占主导 | ★★ |
| **人形机器人增量** | 单台用14-20个谐波减速器，需求爆发弹性最大 | 较少用于人形 | 部分轻量化替代 |

**关键判断**：减速器是人形机器人BOM占比约15%的核心部件。绿的谐波单价已降至1300元（哈默纳科的一半），2027年全球或出现超20%供给缺口。这是中国供应链确定性最强的环节之一。

### 3.2 丝杠/轴承（行星滚柱丝杠）

| 维度 | 详情 |
|------|------|
| **商业模式** | 卖设备（非标定制，精度要求极高） |
| **毛利率区间** | 30-45% |
| **竞争格局** | Rollvis/GSA/Ewellix海外合计占80%+；国产化率仅约30%；恒立液压国产市占8%居第一 |
| **壁垒类型** | 精密螺纹磨床（瑞士/德国进口设备，交期1-2年）+ 热处理工艺 + 精度一致性 |
| **中国市场空间** | 人形机器人单台约14根，价值量约2万元；2026年起百亿级潜在市场 |
| **全球市场空间** | 2030年估计超50亿美元（人形拉动） |
| **卡脖子程度** | ★★★★★ **当前最大产能瓶颈，国产替代弹性最大** |

**关键判断**：行星滚柱丝杠是BOM占比最高（约18%）且供给最紧张的环节。核心加工设备年产极低、交期长达1-2年，无法快速扩产。谁先完成产能爬坡和精度提升，谁赢得市场门票。

### 3.3 伺服电机/无框力矩电机/空心杯电机

| 维度 | 详情 |
|------|------|
| **商业模式** | 卖设备（标准化+定制结合） |
| **毛利率区间** | 25-40%（汇川伺服约35%） |
| **竞争格局** | 汇川技术国内伺服市占28-32%连续10年第一；无框力矩电机雷赛/步科领先；空心杯鸣志电器龙头 |
| **壁垒类型** | 电磁设计+精密绕线+散热+控制算法配套 |
| **中国市场空间** | 2026年伺服市场约280亿元；人形电机增量弹性大 |
| **全球市场空间** | 2026年约48亿美元（仅控制器和电机一体化） |
| **卡脖子程度** | ★★★ 伺服国产化率69.5%，高端仍有差距 |
| **国产化进度** | 国产伺服电机单价降至500元（日系的1/3），无框力矩电机国产化率约70% |

### 3.4 传感器（力/视觉/触觉）

| 维度 | 六维力传感器 | 3D视觉 | 触觉传感器/电子皮肤 |
|------|------------|--------|-------------------|
| **商业模式** | 卖设备（高单价、高定制） | 卖模组+算法 | 卖器件+方案 |
| **毛利率区间** | 50-60%+ | 35-50% | 30-45%（培育期可能更低） |
| **竞争格局** | 蓝点触控(未上市)市占72.6%；柯力传感为国产第二 | 奥比中光国内服务机器人3D视觉市占70%+ | 汉威科技国内唯一量产柔性触觉 |
| **壁垒类型** | MEMS工艺+标定算法+抗干扰 | 光学设计+算法+量产一致性 | 材料科学+微纳加工 |
| **中国市场空间** | 传感器占人形BOM约20%，六维力当前单价2万+，量产可降至2000元 | 同左 | 同左 |
| **卡脖子程度** | ★★★★★ 国产化率约40%，技术壁垒最高 | ★★★ | ★★★★★ 国产化率不足20% |

**关键判断**：传感器占人形机器人成本约33.4%，是价值量最高的单一环节。六维力传感器和触觉传感器是当前"卡脖子"最严重的两个细分。2030年全球人形机器人配套传感器市场有望突破3000亿美元（来源：行业研报，注意该数字含各类传感器综合，实际纯机器人传感器市场远小于此）。

### 3.6 工业机器人本体

| 维度 | 详情 |
|------|------|
| **商业模式** | 卖整机（标准化产品）+ 配件/服务 |
| **毛利率区间** | 15-25%（竞争激烈，四大家族约25-35%） |
| **竞争格局** | 埃斯顿2025年国内出货量第一（10.6%）；汇川SCARA第一；四大家族全球合计从50%+降至40%以下 |

| **全球市场空间** | 2025年出货59.8万台；2026年预计超65万台 |
| **卡脖子程度** | ★★ 国产已占据主导地位（中国市场份额56%+） |

**事实**：2025年中国首次成为工业机器人净出口国。埃斯顿+汇川双雄领跑中国市场，外资四大家族份额从2020年的58%降至2025年的52%。

### 3.7 人形机器人本体

| 维度 | 详情 |
|------|------|
| **商业模式** | 卖整机（当前价格1.6万-15万美元）+ 软件订阅/技能服务 |
| **毛利率区间** | 30-60%（头部企业差异大；宇树毛利率60.27%） |
| **竞争格局** | 极度分散，特斯拉/Figure/宇树/智元/1X/傅利叶等各占生态位；2026年H1一级市场融资超1041亿元 |
| **壁垒类型** | 全栈整合（AI+硬件+供应链）+ 规模化量产能力 + 数据飞轮 |
| **中国市场空间** | 2026年国内出货预计突破10万台（工信部口径） |
| **全球市场空间** | 2025年约1.3万台；2030年预计50-100万台规模 |
| **资本市场** | 宇树科技科创板IPO已获批；优必选港股上市；智元/傅利叶/乐聚在IPO排队 |

**关键判断**：人形机器人整机是"星辰大海"赛道，但当前阶段整机公司普遍亏损，且大量未上市。A股投资者当前更应关注已上市的零部件供应链公司，待整机公司上市后再做判断。

### 3.8 AI/具身智能软件

| 维度 | 详情 |

**关键判断**：具身智能软件层当前主要是美国公司主导，中国在数据采集规模上有优势（智元4000平米数据工厂日产3-5万条），但底层芯片和基础大模型仍依赖英伟达生态。

## 六、核心结论

### 6.1 产业阶段判断

2026年是机器人产业的"量产元年"，核心驱动力：
1. **AI突破**：大模型赋予机器人"大脑"，从自动化设备升级为具身智能
2. **政策定调**：具身智能连续2年写入政府工作报告，标准体系(200+项)已发布
3. **量产启动**：特斯拉Optimus Gen3量产启动，目标年底周产2000-2500台
4. **资本涌入**：2026年H1全球具身智能融资超188亿美元，中国超1041亿元
5. **国产反超**：工业机器人国产化率突破56%，首次成为净出口国

### 6.2 投资主线（按确定性排序）

**主线一：特斯拉Optimus供应链（确定性最高）**
三花智控(旋转关节) > 拓普集团(线性执行器) > 绿的谐波(减速器) > 鸣志电器(空心杯电机)

**主线二：核心零部件国产替代（国产化率低、弹性大）**
行星滚柱丝杠(恒立/五洲/贝斯特) > 六维力传感器(柯力传感) > 触觉传感器(汉威科技)

**主线三：工业机器人基本盘（稳定增长，估值较低）**
汇川技术(伺服+SCARA) > 埃斯顿(整机+控制器) > 双环传动(RV减速器)

**主线四：人形机器人整机（A股稀缺标的）**
宇树科技(科创板IPO已获批) > 优必选(港股)，其余整机公司多未上市

### 6.3 反面论据（重要）

1. **量产爬坡是"史上最难"**：马斯克亲口承认，所有部件几乎全新，无现成供应链。特斯拉原计划2025年产5000-10000台，实际仅数百台。
2. **估值已包含大量预期**：绿的谐波PE 300-500倍，五洲新春PE 270倍，鸣志电器PE 310倍。如果量产进度不及预期，估值下杀空间巨大。
3. **整机公司普遍亏损**：国内工业机器人公司(新松/埃夫特/拓斯达)仍处亏损或微利，人形整机仅宇树一家盈利。
4. **五指灵巧手需求存疑**：高盛调研显示双指/三指夹持器已能满足70-90%工业场景，五指灵巧手大规模需求可能推迟。
5. **数据瓶颈未解**：具身智能大模型仍弱于硬件基础，"实验室演示与大规模部署之间有显著距离"(Bessemer)。
