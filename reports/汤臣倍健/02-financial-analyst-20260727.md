## AI研究偏见自觉（A级强制）

市场对汤臣倍健的共识叙事高度同质化：

> “VDS龙头份额仍第一 → 2024是至暗之年 → 2025利润已修复 → 2026Q1营收转正 → PE不到同行一半 + 4%+股息 = 低估值安全垫。”

**本报告的alpha不在复述上述链条，而在检验其裂缝：**

1. **营收仍比2023峰值低33%**，利润低55%——“修复”是低基数反弹，不是重回增长轨道的证明。  
2. **ROE仅7.18%**，远低于巴菲特“优秀生意”的15%门槛；高毛利被销售费用吞噬。  
3. **PE 23x打在受压利润上并不便宜**：若归一化盈利能力回不到两位数ROE，23倍是为复苏期权付费，不是捡烟蒂。  
4. **2026Q1经营现金流暴跌85.57%**、应收账款激增——利润质量短期恶化，与“触底回升”叙事冲突。

**偏见自查**：资料充裕容易把“券商一致增持 + 高股息”误当成确定性；确定性来自生意的资本回报能否回到可接受水平，不来自研报覆盖密度。

### 1.2 趋势解读（巴菲特视角）

- **形状是“尖峰后断崖”，不是平稳成长股**：2023年是渠道与品类共振的高点；2024年一次性打掉约27%收入与63%利润，2025年收入继续下滑、利润靠费用收缩与部分非经常项修复。  
- **利润弹性大于收入**：费用刚性在下行期放大亏损/降幅；上行期（若出现）利润弹性也会很大——但这是经营杠杆，不是护城河。  
- **2026Q1“营收转正、利润仍降”**：收入+4.3%，归母-11.6%，销售费用率同比大幅抬升（华创：+6.21pct至36.5%）——增长靠费投换来，质量存疑。

### 1.3 2023高点后大幅下滑：原因与恢复路径

**下滑主因（多源交叉，非单一借口）：**

| 因子 | 证据 | 影响权重（判断） |
|------|------|------------------|
| 药店渠道结构性承压 | 中康CMH：2024全国药店VDS销售约 **-20%**；医保限制保健品刷卡 | ★★★★★ |
| 核心大单品迭代失误 | 蛋白粉、健力多升级慢于规划；片剂/粉剂销量 **-30%+**，并主动去库存 | ★★★★☆ |
| 价格体系与渠道冲突 | 全渠道发力导致价盘混乱；经销商数量减少（境内经销商2024末较上年 **-200家**） | ★★★☆☆ |
| 消费降级 + 线上白牌分流 | 中高端定位遇性价比冲击；线上亦阶段性策略失误（2024线上 **-25%**） | ★★★☆☆ |

**恢复路径（公司叙事 vs 财务检验）：**

| 路径 | 公司动作 | 财务上要看到什么才算“真恢复” |
|------|----------|------------------------------|
| 线上（抖音/兴趣电商） | 2026Q1线上 **+11%**，抖音高增 | 收入增速持续 > 销售费用增速；净利率不因费投塌陷 |
| 线下重塑（商超补药店） | 商超近30%增、对冲药店下滑 | 线下连续两个季度正增且毛利率不恶化 |
| 大单品放量 | 健力多Q1 **+14%**，主品牌 **+6%** | 单品收入回到迭代前水平的70%+ |
| 管理层目标 | “约2年创收入新高”、2026双位数增长 | 营收重新逼近 **90亿+**，且ROE回到 **≥12%** |

**非共识判断**：当前“触底”更像**去库存结束 + 费投前置**的战术反弹；战略恢复的充分条件是药店价值链重建是否成功——这是慢变量，不是一两个季度能证伪或证实的。

**维度结论**：周期顶部清晰、底部形态未确认；利润修复快于收入，含金量一般。  
**评分：★★☆☆☆**

*来源：东方财富主要财务指标；与年报ROE/毛利率交叉一致。*

### 2.2 巴菲特式解读

> 真正伟大的企业，必须拥有持久护城河来保护**优厚的资本回报率**。

- **毛利率67–69%看起来像好生意，但ROE只有7%**——矛盾的关键在**费用结构**：销售费用常年吞噬毛利大头（2025销售费用约26.8亿，接近毛利的63%）。这是“品牌广告驱动的消费品”，不是“提价也不掉量的特许经营权”。  
- **2023年ROE 15.34%曾达标**，证明公司**曾经**能赚到资本成本以上的回报；2024–2025跌至个位数，说明护城河在渠道变迁下被侵蚀，而非短暂会计波动。  
- **扣非增速（+9.5%）低于归母（+19.8%）**：2025利润修复部分来自非经常（处置收益等），经营质量改善幅度被夸大。

### 2.3 反面检验

| 市场说法 | 反面事实 |
|----------|----------|
| “高毛利=定价权” | 定价权应用ROE/ROIC衡量；当前ROIC 6.3% ≈ 无风险利率+风险溢价的下沿，谈不上特许权溢价 |
| “利润已修复” | 相对2023，净利率从18.9%→13.0%，营业利润率21.99%→15.57%，远未修复 |
| “Q1毛利率再升” | 毛利率升 partly 因线上占比提升；同时销售费用率 +6pct，净利率 **-4.5pct** |

**维度结论**：毛利率优秀但资本回报平庸；从巴菲特标准看，当前是“曾经优秀、正在平庸化”的消费品，不是复利机器。  
**评分：★★☆☆☆**

### 3.2 解读

**正面（这是报表里最像巴菲特喜欢的部分）：**

- 2025年 **OCF 12.14亿 > 净利 7.82亿（1.55倍）**，利润含金量高；费用付现下降 + 应收管理改善是主因。  
- **CapEx极低（约1.3亿）**，典型轻资产品牌商；FCF约 **10.8亿**，对市值169亿意味着FCF收益率约 **6.4%**（未计理财波动）。  
- 分红能力有真实现金支撑：2025拟 **10派4.5元**，分红现金约6.1亿，占归母净利约 **78%**，占FCF约56%——偏高但尚未“杀鸡取卵”。

**反面（必须写进报告的裂缝）：**

- **2026Q1 OCF仅0.52亿，同比-85.57%**：公司解释为采购及期间费用支付增加；叠加应收账款较年初 **+83%**（授信惯例），短期营运资本占用飙升。  
- 若全年费投前置无法转化为收入加速度，2025的“印钞机”画像会迅速褪色。  
- 筹资端2025净流出12.4亿（还贷+回购+分红），现金余额下降——健康去杠杆，但缓冲垫在变薄。

**维度结论**：2025年现金流质量优秀、资本开支克制，是资产负债表与现金流层面的核心安全垫；2026Q1是明显的黄色警报。  
**评分：★★★★☆**（若Q2 OCF不能修复，下调至★★★）

### 6.2 内在价值区间（巴菲特式保守估计）

采用**业主盈余 ≈ 归一化FCF**思路：

| 方法 | 假设 | 价值区间 |
|------|------|----------|
| A. 保守永续（无增长） | 归一化业主盈余取2024–2025 FCF均值≈7.3亿，要求回报10% | 73亿 → **约4.3元/股**（过苛，忽略净现金） |
| B. 净现金+经营价值 | 净金融资产51亿 + 经营利润9.75亿×12–15倍 | 51+117~146 = **168–197亿** → **9.9–11.6元** |
| C. 分红贴现粗算 | 股息0.45、永续增长2%、要求回报9% | 0.45/(9%-2%)≈6.4元，再加净现金/股≈3.0 → **~9.4元** |
| D. 三情景概率加权（主观） | 乐20%/中50%/悲30% | 0.2×18.5+0.5×10.9+0.3×5.6 ≈ **10.9元** |

**中枢内在价值约 10–12 元**；当前价 **10.03元 ≈ 公允价值附近略折价**，安全边际薄。

### 6.3 安全边际结论

| 问题 | 回答 |
|------|------|
| 有没有“半价买入优质生意”的安全边际？ | **没有**。价格≈价值中枢下沿 |
| 下跌保护主要靠什么？ | **净现金~30%市值 + 高股息 + 低负债**，不是盈利能力 |

**维度结论**：更接近“合理价买一般偏好资产”，而非“便宜价买伟大企业”。对巴菲特框架：可关注、可等待更好价格或更好经营证据，不宜因股息幻觉重仓。
