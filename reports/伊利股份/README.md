## 综合投资评级

### ★★★★（推荐建仓）

**核心逻辑**：
- 一流生意（消费品刚需 + 规模效应 + 品牌护城河）
- 一流财务（ROE 21% + 现金流优秀 + 6% 股息率）
- 合理估值（PE 15x 处于历史中低位）
- 三大风险已识别并可缓释

**估值**：
- 当前价 ~27 元（PE 14.84x）
- 中性目标价 41 元（PE 18x × 8% 增速）
- 期望年化回报 12-15%

**适合投资者类型**：
- 价值投资者（低估值 + 高股息 + 稳健）
- 长期持有者（消费品龙头的复利机会）
- 红利策略（6% 股息率 + 持续分红历史）

**不适合**：
- 短期交易者（缺乏催化剂）
- 追求爆发的成长股投资者（非爆发性增长）

## 关键风险与机会

### 最大机会
1. **估值修复**：PE 15x → 18-20x，对应 +25-35% 估值提升
2. **股息复利**：6% 股息率持续，提供长期复利基础
3. **市占率持续提升**：双寡头格局下伊利仍在扩大领先

### 最大风险
1. **食品安全黑天鹅**（致命风险）：参考 2008 三鹿事件
2. **出生率下滑**（长期风险）：奶粉业务持续萎缩
3. **原奶价格暴涨**（中期风险）：毛利率波动 5-10ppt
4. **管理层接班**（中期风险）：潘刚 56 岁，接班人未明
