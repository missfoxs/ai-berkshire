> 角色：business-analyst（段永平投资视角）

> 报告日期：2026-09-15

## 一、商业模式本质：包装调味菜的"小而美"龙头

### 1.1 生意定义

涪陵榨菜的核心生意是**以涪陵产区青菜头为原料、经传统三腌三榨工艺加工、以独立小包装形式销售给C端家庭和B端餐饮渠道的佐餐调味菜**。这是一个典型的"原料-加工-品牌-渠道"四段式传统快消生意。

- **核心品牌矩阵**：乌江（榨菜主力，2025年消费者偏好度77.7%）+ 惠通（泡菜）+ 备得福（东北市场）+ 邱氏菜业（萝卜）
- **核心SKU**：80g脆口榨菜、70g清淡榨菜、60g轻盐榨菜、22g迷你榨菜（餐饮渠道）
- **商业模式图**：
  ```
  涪陵产区农户（青菜头）
        ↓ （采购/合作种植）
  涪陵/辽宁/眉山/湖南 五大生产基地
        ↓ （三腌三榨+自动化包装）
  2632家经销商+电商+餐饮/出口
        ↓
  C端家庭（约80%）+ B端餐饮（约20%）
  ```

## 二、飞轮效应：渠道-品牌-规模-议价能力的正循环

### 2.1 飞轮模型

```
规模采购（青菜头）→ 原料议价权（成本优势）
        ↓
规模生产（18万吨产能）→ 制造费用摊薄 → 55%+毛利率
        ↓
品牌投入 → 乌江品牌资产积累（消费者偏好77.7%）
        ↓
经销商愿意卖（高毛利+高周转）→ 终端铺货密度
        ↓
消费触达 → 复购/口碑 → 继续买乌江
        ↓
回到规模采购（飞轮加速）
```

### 2.2 经销商体系演化（关键变量）

| 时点 | 经销商数量 | 关键变化 |
|------|----------|---------|
| 2018年 | ~1900家 | 高速增长期，全国扩张 |
| 2020年 | 2648家 | 疫情期触达消费者 |
| 2023年末 | 3239家 | 高峰，渠道过度下沉 |
| 2024年末 | 2632家 | **净减607家（-18.74%）**，华南大区砍58% |
| 2025年6月末 | 2446家 | 继续净减186家 |

**经销商锐减的双面性**：
- **正面**：清理"乱价、窜货、布局不合理"的经销商，稳住价盘（2024年吨价回升）
- **负面**：渠道下沉和覆盖密度受损，2024年华南/华北/中原/西北大区均负增长
- **段永平视角**：段永平反复强调"做对的事情，把事情做对"。经销商从3239家骤降到2446家是"对的事情"（清理低质经销商），但执行中要避免"把事情做错"（好的经销商也被误伤）

**飞轮当前状态**：**卡顿中**——渠道改革、品类延伸都在"做对的事"，但飞轮转速明显下降，2024-2025连续两年营收下滑即是飞轮减弱的证据。

★ 评分：飞轮效应 ★★★（3/5），存在但已大幅减弱。

## 三、护城河分析（逐一评级）

### 3.1 品牌（乌江）—— ★★★★（4/5）

**事实：**
- 2025年消费者品牌偏好度：乌江77.7%，六必居7.7%，吉香居6.9%（数据来源：人民日报社/乌江榨菜联合调研）
- 2025年榨菜行业市占率：涪陵榨菜32%，乌江品牌单独51.7%（数据来源：市场调研在线）
- 乌江品牌价值超百亿，多次蝉联中国驰名商标

**但需注意的"品牌暗伤"**：
- 2017年市占率峰值40% → 2021年降至33.3% → 2024年估算仍约30%-32%
- 提价过频导致部分价格敏感型消费者流失，"涪陵榨菜=贵"成为消费者认知
- 年轻消费者对"传统老品牌"情感弱化

**段永平点评**：乌江是"护城河很深的品牌"——这是段永平2013年参加贵州茅台股东大会时反复强调的"好生意"要素。涪陵榨菜在榨菜细分品类中确实拥有茅台式的品牌护城河，**但要警惕：品牌护城河在品类内是宽的，跨品类（如豆瓣酱、调味品）护城河几乎不存在**。

### 3.2 转换成本（消费者习惯）—— ★★★（3/5）

榨菜是低值低频快消品，单包2-3元，单次决策成本极低，**几乎无转换成本**。但存在两类"软性锁定"：

1. **口味记忆锁定**：消费者从童年起就吃乌江榨菜，口味记忆形成长期偏好（中老年群体）
2. **餐饮厨师习惯**：B端餐饮厨师在配菜（如酸菜鱼、面浇头）时倾向用乌江（标准化程度高）

**段永平视角**：低转换成本不可怕，可怕的是"同质化"。**乌江通过口味+品牌双因素形成的弱锁定在榨菜赛道内有效，但跨场景（休闲零食、年轻佐餐）失效**。

### 3.3 网络效应 —— ★（1/5） 不适用

**段永平的生意经里强调"网络效应是最高级护城河"**（如微信、美团），但包装榨菜作为传统快消，**无网络效应**。这与所有传统消费品（除极少数如茅台社交属性）一致。

**评价**：这是生意的根本限制，但并非致命缺点。巴菲特、芒格、段永平投资的可口可乐、苹果、伯克希尔本身也无网络效应。

### 3.4 规模效应（成本+渠道）—— ★★★★（4/5）

**原料端：**
- 涪陵产区青菜头种植面积约72万亩，占全国60%以上
- 公司+农户合作模式覆盖核心产区，2025H1青菜头采购3.36亿元
- 涪陵产区特殊的紫色土壤+长江沿岸小气候造就的原料品质，**这是公司最强的实物护城河**

**生产端：**
- 涪陵/辽宁/眉山/湖南 四大基地，合计产能18万吨/年
- 2024年榨菜销量11.14万吨，产能利用率不足80%
- "中国榨菜城"项目规划30万吨精品榨菜+10万吨泡菜，但远期项目（投资50亿元）

**渠道端：**
- 2632家经销商覆盖全国，**渠道密度远超同行**（鱼泉约500-800家、吉香居依赖大商超）
- KA渠道（沃尔玛/大润发/永辉）覆盖率行业第一

**但规模效应的边际递减**：
- 东北生产基地利用率不到40%（2024年数据）
- 三大基地产能合计18万吨，2024年榨菜销量11.14万吨
- 销量从2020年13.56万吨下滑至2024年11.14万吨，**产能反向闲置**——这是规模效应"反噬"的表现

### 3.5 地理标志保护（涪陵产区）—— ★★★★★（5/5）

**这是涪陵榨菜最被低估、但最坚实的护城河**。

**事实：**
- 国家地理标志产品保护范围以涪陵区行政区划为准
- 原料青菜头必须产自涪陵产区（这是国家地理标志保护的核心条款）
- 来源：涪陵榨菜地理标志产品保护规定（2023年5月）

**为什么这是5星护城河**：
- 任何竞争对手都无法复制涪陵产区的特殊土壤和气候
- 鱼泉榨菜虽在重庆，原料也只能从涪陵产区采购（无法自己种出同等品质）
- 这是**类"茅台镇"式护城河**——物理层面不可复制
- 涪陵产区青菜头占成本35%-45%，价格波动直接影响毛利率
- 2010-2024年涪陵榨菜稳定获得超额毛利率，地理标志保护是底层原因

**段永平点评**：段永平多次表示"差异化是最好的护城河"。涪陵产区的地理标志保护是**法律+物理双层差异化**，比单纯的品牌差异化更深。**这一条护城河比品牌还硬**。

### 3.6 护城河综合评分

| 护城河类型 | 评分 | 段永平评价 |
|----------|------|----------|
| 品牌（乌江） | ★★★★ | 强但近年受提价反噬 |
| 转换成本 | ★★★ | 仅品类内有效 |
| 网络效应 | ★ | 不适用 |
| 规模效应 | ★★★★ | 强但产能闲置 |
| 地理标志 | ★★★★★ | 物理+法律双壁垒，最深 |
| **加权综合** | **★★★★** | **护城河仍然深，但飞轮减弱** |

## 四、用户/客户价值：三层利益相关方

### 4.1 消费者价值

**独特价值：**
- **便利**：开袋即食，0-2分钟解决一餐的"饭搭子"
- **稳定口感**：全国统一品质，远超散装榨菜和家庭自制
- **价格弹性**：从1元（流通品）到15元（高端"只有乌江"系列），覆盖所有收入阶层
- **文化记忆**：承载70/80后"打工人午餐"情怀

**但"消费者价值"在弱化**：
- 高铁+外卖时代，旅途佐餐场景消失
- 健康消费趋势下，榨菜被贴上"高盐不健康"标签
- Z世代更倾向新鲜、现制、轻食，榨菜被"老龄化"

### 4.2 经销商价值

**独特价值：**
- **高毛利空间**：乌江榨菜经销商毛利率约15-20%，远高于同类调味品
- **强动销**：乌江品牌力带来自然动销，经销商无需大力推销
- **稳定价盘**：2024年清理乱价经销商后，价盘有所恢复

**但经销商数量从3239家降至2446家，-24.5%**——这意味着公司"让渡给经销商的价值"在收缩。好的经销商被砍的同时，**剩余经销商的盈利能力是否依然优秀**？这是2025-2026年需要重点跟踪的。

### 4.3 农户价值

**独特价值：**
- **保底收购**：涪陵榨菜+农户合作模式，给农户稳定的青菜头销路
- **技术指导**：提供种子、种植技术、肥料
- **季节性就业**：榨菜加工工厂是涪陵区吸纳就业的核心

**社会价值**：
- 涪陵区青菜头种植约72万亩，覆盖数十万农户
- 公司+农户模式是乡村振兴典型案例
- 2025H1青菜头采购3.36亿元，按25%种植成本占比估算，惠及约5-8万户农户

★ 评分：利益相关方价值创造 ★★★（3/5），三方都有价值但都面临"价值感下降"的问题。

## 五、业务矩阵与协同："榨菜+"与"豆瓣酱+"双轮战略

### 5.1 当前业务矩阵

```
                高毛利   低毛利
                ┌─────┐ ┌─────┐
       高增长   │  -  │ │  -  │
                ├─────┤ ├─────┤
       低增长   │榨菜 │ │  -  │
                │(85%) │ │     │
                ├─────┤ ├─────┤
       下滑     │泡菜 │ │萝卜 │
                │(10%) │ │(2%) │
                └─────┘ └─────┘
```

### 5.2 业务延伸的逐项验证（反偏见）

| 业务 | 2024年规模 | 同比 | 真实增长还是包袱？ |
|------|----------|------|-----------------|
| 榨菜（主业） | 20.44亿 | -1.5% | **主业承压**，但85%占比说明核心竞争力未失 |
| 泡菜 | 2.30亿 | +2.2% | **真实增长但量价失衡**：销量+16%但吨价-12%，靠"以价换量" |
| 萝卜 | 0.46亿 | -24.4% | **持续萎缩**，2025H1靠风干萝卜新品+38%才止跌 |
| 其他（含酱） | 0.62亿 | -26.0% | **持续萎缩**，豆瓣酱尚未起量 |
| 味滋美并购 | 拟收购51% | — | **2025年10月终止**，并购失败 |
| 餐饮业务 | ~1.0亿 | +30% | **真增长**，2025H1餐饮+37%，B端突破方向 |

### 5.3 协同逻辑检验

**段永平反复强调："好生意要专注"**。涪陵榨菜的"榨菜+"和"豆瓣酱+"双轮战略是否专注？

**事实判断**：
- 2024年泡菜/萝卜/其他三项合计3.38亿，占比14.2%——业务多元化的"事实"已存在
- 2025年4月拟收购味滋美（川味复调B端）→ 2025年10月终止，**首次跨品类外延并购失败**
- 2018年曾拟收购四川恒星、四川味之浓进军豆瓣酱领域，**亦未成功**
- 2026年公司在年报中仍将"中式调味酱、豆瓣酱、复合调味料、火锅底料"定位为"未来核心支柱品类"

**段永平视角判断**：
- 段永平多次表示"扩张常常是多元化的开始，也是主业衰落的开始"
- 涪陵榨菜的"榨菜+萝卜+泡菜"延伸在工艺/原料/渠道上具有协同（共享青菜头、共享经销商），是合理延伸
- 但"豆瓣酱+"是**跨工艺、跨渠道、跨品牌**的扩张，且**两次外延并购均失败**，应警惕"战略焦虑"导致动作变形

★ 评分：业务矩阵协同 ★★（2/5），延伸品类的协同尚未形成事实上的增长。

## 六、段永平"好生意"标准评估

### 6.1 差异化：★★★★（4/5）

**强差异化点：**
- 涪陵产区地理标志——物理+法律双层壁垒，竞品无法复制
- 三腌三榨传统工艺——涪陵榨菜非物质文化遗产
- 乌江品牌——消费者偏好度77.7%
- 22年工艺积累（2000年改制至今）

**弱差异化点：**
- 包装榨菜本身高度同质化（鱼泉、吉香居、味聚特产品形态几乎一样）
- 渠道覆盖差异逐步缩小（竞品也进入商超、电商）
- "轻盐/健康"是行业趋势，差异化不持久

### 6.2 定价权：★★★（3/5）—— **关键失分项**

**历史提价能力堪称"榨茅"**：

| 时点 | 提价方式 | 提价幅度 | 销量反应 |
|------|---------|---------|---------|
| 2008年 | 0.5元/70g → 1元/100g | +40% | -24%（2年恢复） |
| 2012-2014年 | 连续缩规格变相提价 | 累计~60% | -10%（1.5年恢复） |
| 2016-2017年 | 直接提价8%-17% | — | 2016-2018量价齐升 |
| 2018-2019年 | 缩规格+直接提价 | 累计~30% | 销量下滑 |
| 2020年 | 继续缩规格 | 累计~30% | 疫情居家，销量+14% |
| 2021年11月 | 出厂价上调3%-19% | — | **2022-2024销量持续下滑** |

**2008-2020年累计提价13次，单包从0.5元涨到3元+，涨幅600%**——这是A股市场最经典的"提价驱动型"成长股案例。

**但定价权正在失效**：
- 2021年提价后销量恢复周期显著延长（从1.5年延长到3年+）
- 2022-2024年销量连续3年下滑，2024年11.14万吨 vs 2020年13.56万吨，**销量蒸发18%**
- 2024年起公司转向"加量不加价"（60+6g、80+8g），实际是**隐性降价**
- 2025H1吨价仅+1.6%，**提价空间已触及天花板**

**段永平视角**：
- 段永平认为"定价权是好生意的核心"
- 涪陵榨菜历史定价权极强（"提价能力超过茅台"是市场夸张说法，但确实很强）
- 但**当前定价权正在失效**——这是从"好生意"向"普通生意"滑落的关键信号
- 段永平对"产品提价能力"的判断标准是"提价后销量恢复周期"，涪陵榨菜从这个角度看**正在退化**

### 6.3 可持续竞争优势：★★★★（4/5）

- 涪陵产区地理标志保护（最硬壁垒，5星）
- 乌江品牌资产（4星）
- 2632家经销商网络（4星）
- 22年工艺积累（4星）
- 现金流稳定（2024年经营性现金流7.74亿）

**但竞争优势的"有效性"在下降**：
- 品牌：受提价反噬，年轻群体认知弱化
- 渠道：经销商大幅精简，渠道密度下降
- 销量：2020-2024年销量从13.56万吨降至11.14万吨

### 6.4 生意的简单性：★★★★★（5/5）

**这是涪陵榨菜最大的段永平式优点**：
- 生意极其简单——青菜头 → 加工 → 包装 → 卖到全国
- 财务极其干净——基本无负债（资产负债率<20%），无复杂衍生品
- 商业模式极易理解——4年级小孩都能听懂
- 现金奶牛特征明显——2024年经营性现金流7.74亿，分红比例43%-60%

**段永平反复强调"不卖看不懂的生意"，涪陵榨菜是"看得懂的生意"的典型代表**。

### 7.2 2022-2024失速根因分析（反偏见检验）

**市场普遍观点**：涪陵榨菜"没落了"。

**数据检验：**

**1. 周期因素（消费场景弱化）—— 主要原因，权重60%**
- 包装榨菜市场规模仅60-80亿元，2007-2021年CAGR仅1.25%（来源：欧睿数据）
- 行业人均消费量仅0.2kg/年，**行业本身接近天花板**
- 核心消费场景在弱化：
  - 旅途佐餐 → 高铁时代取代绿皮火车
  - 工薪配饭 → 外卖平台普及
  - 年轻代际 → Z世代不视榨菜为刚需
- 2010-2021年包装榨菜消费量CAGR仅1.25%，**行业增长本身已基本停滞**
- 提价透支：2008-2020年累计提价13次，单包从0.5元涨到3元+，**2021年提价触及价格敏感型消费者天花板**

**2. 结构因素（赛道天花板低）—— 次要原因，权重30%**
- 包装榨菜60-80亿市场规模，对应乌江51.7%市占率也只有30-40亿
- 行业整体已进入"存量博弈"阶段
- 替代品挤压：饭扫光、味聚特（烧椒酱）、老干妈（豆豉）、新式复合调料
- "榨菜+"延伸尚未形成第二增长曲线（萝卜/泡菜/豆瓣酱均未起量）

**3. 战略因素（公司自身动作）—— 加速原因，权重10%**
- 经销商过度扩张：2023年3239家 → 2024年砍至2632家
- 渠道窜货、乱价导致价盘失控
- 多次并购失败（2018年恒星/味之浓、2025年味滋美）
- 提价节奏过频，透支消费者信任

**结论（反偏见）**：
- **失速主要是周期因素（消费场景弱化+提价透支），权重60%**
- 结构性因素（赛道天花板）权重30%是基础性约束，但行业本身仍在（只是不再扩张）
- 公司自身动作的失分权重10%但影响巨大（清经销商、并购失败）
- **失速不是"结构性的不可逆"**——2025H1 Q2收入转正（+7.59%）就是周期触底反弹的证据
- 但**未来增速将远低于2014-2018年**，从"高增长"变成"低增长+高分红"的现金牛型公司

### 7.3 渠道-品牌-规模-议价能力的飞轮现状

**当前飞轮转速：**
- 采购规模：青菜头采购稳定但议价权仍强（2025H1采购3.36亿）
- 生产规模：18万吨产能利用率80%，**规模效应开始反噬**
- 品牌投入：维持但未加大（销售费用率从2024H1的10%升至2025H1的14.9%）
- 渠道：2446家经销商，密度恢复中
- 终端：餐饮+37%、出口+15%，新增长极

**段永平点评**：飞轮仍在转，但转速明显降低，**从"高速成长股"变成了"低速现金牛"**。

## 八、段永平视角总体结论

### 8.1 是不是"好生意"？

**答：曾经是，现在仍是，但增速不再。**

涪陵榨菜在2014-2020年是典型的段永平"好生意"样本：
- 差异化（乌江品牌+涪陵产区）
- 专注（榨菜单品占比85%）
- 长期主义（22年只做榨菜）
- 看得懂（商业模式极简）
- 现金流强（无负债、分红高）

但**2022-2024年的失速不是管理失误，是行业周期+赛道天花板+消费者代际转移三重因素叠加**。段永平看生意的核心是"未来现金流"——涪陵榨菜未来现金流仍稳定，但**增速预期必须大幅下调**。

### 8.2 失速是周期还是结构？

**答：周期为主（60%），结构为辅（30%），公司动作为辅（10%）。**

- 周期：消费场景弱化（高铁+外卖+Z世代）+ 提价透支——这部分2025年开始触底反弹
- 结构：行业天花板（60-80亿规模、CAGR 1.25%）——这部分不可逆，未来增长靠品类延伸
- 动作：渠道改革+品类拓展——这部分执行尚可，但味滋美并购失败暴露战略焦虑

**2025H1 Q2收入+7.59%是关键转折信号**——如果2025全年能保持低个位数增长，说明周期触底已确认。

### 8.3 业务延伸是增长还是包袱？

**答：榨菜+萝卜+泡菜延伸合理但尚未起量；豆瓣酱+跨品类外延失败且包袱概率高。**

- 榨菜 → 萝卜/泡菜：工艺协同、原料协同、渠道协同均成立，但目前3.38亿规模仍小
- 榨菜 → 豆瓣酱/复调/火锅底料：跨工艺、跨渠道，**两次外延并购均失败**，是包袱概率高
- 段永平逻辑："扩张常常是衰落的开始"——涪陵榨菜应**回归主业**（榨菜+萝卜+泡菜），不要被"第二增长曲线"叙事绑架

### 8.4 好生意评估总评分

| 维度 | 评分 | 备注 |
|------|------|------|
| 商业模式清晰度 | ★★★★ | 简单易懂 |
| 飞轮效应 | ★★★ | 存在但减弱 |
| 品牌护城河 | ★★★★ | 强但受提价反噬 |
| 地理标志护城河 | ★★★★★ | 最深最硬 |
| 规模效应 | ★★★★ | 强但产能闲置 |
| 定价权 | ★★★ | 曾经极强，现已失效 |
| 业务延伸协同 | ★★ | 跨品类延伸包袱概率高 |
| 管理层 | ★★★ | 改革方向对，但执行有反复 |
| 现金流质量 | ★★★★★ | 经营性现金流稳定，无负债 |
| **综合** | **★★★★** | **好生意褪色中，仍是好生意但增速降级** |

### 8.5 段永平视角的核心结论

> 涪陵榨菜就像一个**曾经的"榨菜茅台"，现在变成"榨菜农夫山泉"**——
> 护城河仍在（地理标志+品牌+渠道），但定价权已触及天花板，增速从"高增长"变成"低增长+高分红"。
> 
> **段永平可能会投，但会等到估值合理、且管理层的"扩张焦虑"消退后**。当前公司最该做的不是并购豆瓣酱，而是**回归榨菜主业+提升分红比例+用现金回购股票**——这才是"不卖看不懂的生意"的段式投资逻辑。
> 
> **风险点**：管理层在"业绩压力"下是否会继续盲目扩张（如同2018年和2025年）？这是投资者需要持续跟踪的核心风险。
> 
> **机会点**：2025-2026年是周期触底+股息率（4.7-7%）+ 渠道改革见效的三重共振期，但需警惕"扩张动作"反复。
