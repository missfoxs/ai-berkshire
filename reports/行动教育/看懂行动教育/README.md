## 核心结论

> **行动教育是一台"高毛利+高现金流+高分红"的三高印钞机（毛利率79%、净利率39%、ROE 31%、分红率93%），但护城河不够深（依赖创始人IP、行业进入壁垒低）。当前20倍PE合理偏低，扣除21亿账上现金后仅13.5倍PE。中性情景目标价67.60元（+25%），适合作为组合中5%-8%的"现金牛"配置，但不应重仓，核心风险是预付费监管立法和创始人依赖。**
