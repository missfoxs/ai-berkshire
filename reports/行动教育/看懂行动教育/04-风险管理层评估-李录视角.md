# 行动教育（605098.SH）风险与管理层深度评估
## 李录视角：穿透管理层、识别真风险、判断长期确定性

**研究日期**：2026年7月22日  
**研究框架**：李录投资四问——(1) 管理层是"对的人"吗？ (2) 这个生意10年后还在吗？ (3) 确定性从哪来？ (4) 什么样的风险可能颠覆这个生意？

## 一、管理层评估：李践是"对的人"吗？

### 1.1 创始人画像

| 维度 | 事实 | 评价 |
|------|------|------|
| **年龄** | 61岁（1965年生），中国香港永久居民 | 创业30年+，精力充沛，2027年任期届满前无退休风险 |

数据来源：2025年年报、东方财富高管持股数据

### 1.2 能力圈评估

李践的能力圈集中在**中小企业管理培训**这一垂直领域，在过去近20年中从未跨界。从风驰广告到行动教育，本质上都是"to B端、服务中小企业主"的生意。他在这个领域的认知深度体现在：

- **课程产品持续迭代**：从1.0《赢利模式》到4.0"实效教育+AI教育"，内容不断演进
- **对客户痛点的深刻理解**：中小企业主"时间少、预算有限、要求立竿见影"的需求被精准捕捉，浓缩EMBA仅需3天，校长EMBA为1.5年制
- **商业模式设计精妙**：漏斗型课程体系（浓缩EMBA引流→校长EMBA深绑→咨询延伸），预收款模式锁定现金流

**但存在能力圈风险**：李践并非企业管理学术背景出身，而是"实战派+成功学基因"。公司在研发上的投入长期偏低（2025年已有所改善，但仍显著低于销售费用）。过度依赖个人IP是核心风险——历史上李践一人贡献了公司40%-51%的课程收入。

诚信方面存在正面与负面证据，需要逐条辨析：

**正面证据**：

|------|------|

| 股东会表决 | 2026年股东会9项议案同意率均超99.99% |

### 1.4 战略眼光评估

**亮点**：
- **2023年启动大客户战略**，精准把握了中小企业培训预算收缩的趋势，转向预算更稳定的大型企业客户
- **2025年提出百校计划**，以轻资产直营模式进行全国化扩张，避免了加盟模式带来的品控风险
- **2026年全面拥抱AI**，与钉钉战略合作，推出AI相关课程，战略反应速度较快
- **股权激励设定三年高增长目标**（2026-2028年CAGR 20%），将管理层利益与股东利益对齐

**隐忧**：
- 百校计划从"过去10年只输出3位分校总经理"到"一年复制10位"，人才供给质量存疑
- AI战略目前停留在"课程层面"，能否真正构建技术壁垒存在不确定性
- 新业务（如AI咨询、海外拓展）缺乏历史验证

### 1.5 资本配置能力评估

这是李践最值得深入讨论的维度：

| 资本配置行为 | 评价 |
|-------------|------|
| **93%分红率** | 双刃剑：对现金流充裕的成熟业务是股东友好之举；但对于处于百校扩张+AI投入期的公司，可能反映管理层缺乏更好的资本运用渠道 |
| **IPO募资使用** | 原计划投入"智慧管理培训基地"等项目，但项目更名、投入节奏等信息透明度不足 |
| **上市前大额分红** | 上市前即派发4000余万元，存在"把利润分完再融资"的嫌疑 |
| **未进行大规模并购** | 以行动教育在行业的龙头地位和近18亿在手现金，未通过并购整合行业，说明管理层对并购扩张持保守态度 |

**关于93%分红率的深度辨析**：

正面解读：
- 公司轻资产模式，百校扩张单个分校投入小（轻资产直营），不需要大量资本支出
- 合同负债（预收款）12.23亿元是先收钱后服务，无需垫资扩张
- 高分红本身是管理层信心的体现——如果预计未来会亏损，不会把现金全分掉

负面解读（李录视角会关注）：
- 一个处于"百校扩张+AI战略"的公司，把93%的利润分掉，说明这些所谓"战略"并不真的需要钱——那它们到底需要什么？是需要钱买不到的东西（人才、品牌、时间），还是这些战略本身就是低资本强度的自然延伸？
- 如果公司自己都找不到年化回报超过资金成本（约8%-10%）的再投资机会，那93%分红率是理性的——但这同时也说明百校扩张的边际回报可能不如想象的那么高
- 李录偏爱"能将利润高效再投资"的企业（如伯克希尔的保险浮存金模型、比亚迪的持续产能投资），93%的分红率恰好说明行动教育不具备这种能力

**资本配置结论**：李践的资本配置能力处于"合格但不卓越"的水平。高分红是一种"不犯错"的策略——在市场普遍存在管理层"乱花钱"问题的A股，能把钱还给股东已经是前20%的管理层了。但真正卓越的资本配置者（如段永平的分红+回购平衡、巴菲特的利润再投资）仍在更高的维度上。

## 二、监管风险评估 ★★★★（风险较高）

### 2.1 核心风险：行业属性导致的"监管套利"

行动教育面临一个结构性困境：它处于"企业管理培训"的灰色地带，既不完全属于传统教育培训（不受双减政策直接冲击），又确实在开展"培训"业务。目前的监管利好恰恰来自这种模糊性，但模糊性本质上是风险而非护城河。

| 监管领域 | 当前状态 | 潜在风险 |
|----------|---------|----------|
| **校外培训监管** | 主要针对K12学科培训，企业管理培训不受影响 | 若监管范围扩大至"成人非学历培训"，将面临办学许可、预收费限额、资金监管等要求 |
| **预收费监管** | 目前无专门针对企业管理培训的预付费监管政策 | 国务院《预付式消费监督管理条例》已列为预备立法项目，一旦出台将适用于全行业 |
| **教育资质** | 公司持"视频网络制作"等资质，非传统教育资质 | 若被要求取得办学许可证，存在不合规风险 |
| **增值税** | 2026年起非学历教育服务不再免征增值税 | 已实施，影响税负成本 |
| **税务稽查** | 教培行业被税务部门列为重点关注行业 | 预收款模式的税务处理（收入确认时点）是潜在稽查重点 |

### 2.2 预付费监管：最大的"灰犀牛"

国务院已将《预付式消费监督管理条例》列为预备制定项目。若该条例参照当前校外培训行业的监管逻辑，可能要求：
- 预收资金按比例存入监管账户（30%-50%）
- 不得一次性收取超过一定期限的费用
- 全面纳入统一监管平台

这对行动教育的冲击将是结构性的：
- **合同负债12.23亿元**（2026Q1）是公司最重要的经营缓冲垫
- 若预收款被限额或强制存管，现金流模型将发生根本改变
- 但也会加速行业洗牌，提高进入壁垒，利好龙头

### 2.3 监管评分

| 子维度 | 评分 |
|--------|------|
| 政策冲击概率 | ★★★（预付费立法确定性高，但针对企管培训的专项监管概率低） |
| 冲击程度 | ★★★★（若实施预收费限额，现金流模型将受重大影响） |
| 公司应对能力 | ★★★（行业龙头地位赋予一定议价和适应能力） |
| **综合** | **★★★（中等偏高，密切关注预付费立法进展）** |

## 三、竞争风险评估 ★★（风险较低）

### 3.1 竞争格局全景

| 竞争类型 | 代表 | 威胁程度 | 说明 |
|----------|------|----------|------|
| **直接竞争** | 创业黑马、和君商学、时代光华 | **★★**（低） | 创业黑马2023年营收仅2.71亿，市占率0.03%。行动教育市占率0.07%，两者差距正在扩大 |
| **高校商学院** | 北大光华、长江商学院、中欧 | **★★**（低） | 差异化定位：行动教育3天浓缩课程vs MBA 2年制；价格更低；定位企业中层团课 |
| **跨国咨询** | 麦肯锡、BCG | **★**（极低） | 目标客群完全不同，不存在直接竞争 |
| **线上平台** | 得到、混沌学园、各类知识付费 | **★★★**（中等） | 线上内容对低端培训有一定替代效应，但难以替代线下深度课程+圈层社交 |
| **AI工具** | ChatGPT、各类AI决策辅助工具 | **★★★**（中等） | 对"知识传递型"培训构成威胁，但对"行为改变型"培训威胁有限 |

### 3.2 行动教育的竞争壁垒

| 壁垒 | 是否真实 | 可维持性 |
|------|---------|----------|
| **品牌认知** | 真实——"实效管理第一股"的标签在中小企业主群体中有认知度 | 中等——品牌容易被模仿 |
| **客户转介绍网络** | 真实——85%复购转介绍率，NPS 76.9% | 强——网络效应随时间增强 |
| **预收款+合同负债** | 真实——12.23亿合同负债是强大的经营缓冲 | 中——若遭遇预付费监管，优势减弱 |
| **课程体系** | 中等——有完整漏斗型体系但内容可复制性强 | 弱——课程内容知识产权保护困难 |
| **师资** | 中等——李践个人IP是核心壁垒但也构成依赖 | 弱——关键人风险 |
| **规模效应** | 真实——2025年毛利率78.86%，净利率39.84%，远超行业平均 | 强——随着百校推进，规模优势会增强 |

### 3.3 线上替代风险：需要正视的结构性威胁

线上培训不是"是否替代线下"，而是"替代多少"的问题。

**行动教育的防御优势**：
- 线下课程的核心价值不只是知识传递，更是"圈层社交"+"现场氛围"+"行为改变"
- 3天浓缩EMBA的高密度沉浸式体验难以在线上复制
- 大客户（郎酒续单1580万/年）购买的不仅是课程，更是"学习官陪伴+持续跟进落地"的服务体系

**线上替代的渗透领域**：
- 低端标准化课程（如基础财务知识、人力资源入门）将率先被AI和线上内容替代
- 中小企业预算收缩时，部分客户会先用线上内容"试水"
- 但这可能反过来成为行动教育的引流渠道（漏斗效应）

**一个值得警惕的数据**：2025年51.5%的企业培训经费使用率低于80%，说明即使有钱，企业也不一定花在培训上。如果线上AI工具（如AI领导力教练、培训智能体）以1/10的价格提供了60%的效果，客户可能更倾向于选择性价比更高的方案。

| 潜在进入者威胁 | ★★（低，品牌+网络效应形成壁垒） |
| 线上替代威胁 | ★★★（中等，需要持续跟踪） |
| **综合** | **★★（低，现有竞争格局有利，最大威胁不是竞争而是颠覆）** |

## 四、业务风险评估：百校扩张的隐忧 ★★★（中等）

### 4.1 扩张逻辑

百校计划的基本假设：将已验证的单校盈利模型复制到100个城市，实现收入从8亿到20-30亿的跃迁。

**"已验证"是真的已验证了吗？** 
- 2025年首批6家分校刚开业，最早的开业时间不足一年
- "6-12个月盈亏平衡"是行业常规假设，行动教育自身的分校数据尚未得到充分验证
- 第一批分校选址大概率是"最容易成功"的城市（经济发达、付费意愿强），后续扩张将面临边际递减

### 4.2 核心瓶颈：人才而非资本

| 瓶颈维度 | 分析 |
|----------|------|
| **分校总经理供给** | 过去10年只培养出3位分校总经理 → 2025年一年复制出10位。速度提升10倍，质量能否保证？"AI助力选人、育人"听起来更像口号而非已验证的方法论 |
| **讲师供给** | 核心课程仍高度依赖李践和少数资深讲师。100个分校需要多少合格讲师？讲师的培养周期远长于销售人员 |
| **销售团队质量** | 当前689人销售团队，百校计划意味着销售人员可能翻倍甚至翻几倍。管理半径急剧扩大，品控风险上升 |
| **企业文化稀释** | 从10个分校到100个分校，企业文化的传递效率将成指数级衰减 |

### 4.3 扩张模式分析

行动教育采用的是"轻资产直营"模式，这比加盟模式在品控上更优。但"轻资产"也意味着新分校的核心投入是人（分校总经理+销售团队+讲师），而非重资产——这恰恰是更难标准化、更依赖个人能力的扩张要素。

| 指标 | 数据 |
|------|------|
| 2025年新开分校 | 6家（+4家筹备中） |
| 2026年计划新开 | 15家 |
| 2025年单校订单量目标 | 1,000万元/家 |
| 新校盈亏平衡 | 6-12个月（行业常规） |
| 2026年15家新校当年贡献 | 约3,000-5,000万元（单校200-300万） |

从数据看，新分校的节奏是"第一年培育、第二年放量"，这个模型在逻辑上合理，但执行风险在于：
- 15个分校总经理的招聘、培训、考核能否同步跟上
- 经济下行期，新开城市的客户支付意愿可能低于预期

### 4.4 业务风险评分

| 子维度 | 评分 |
|--------|------|
| 扩张逻辑合理性 | ★★★★（方向正确） |
| 执行可行性 | ★★★（人才瓶颈是最大风险） |
| 单校模型可复制性 | ★★★（数据验证周期太短） |
| 对核心人员的依赖 | ★★（高风险，李践不可替代） |
| **综合** | **★★★（中等，扩张方向对但执行有不确定性）** |

## 五、宏观风险评估 ★★★（中等偏高）

### 5.1 客户支付意愿的结构性变化

行动教育的核心客户是**中小企业主**。这个群体的经营景气度直接决定培训预算。

2025年关键数据：
- 企业培训行业即期景气指数仅为**79.5**（荣枯线100），连续五年低于100
- 培训经费缩减企业占比**44.3%**（2024年为39.3%）
- 民营企业中**69.67%预计预算下降**
- 仅**14.3%**的受访者认为行业"总体较好"

**但矛盾的是**：在如此低迷的行业景气度下，行动教育2025年营收仍增长3.55%（H2加速），2026Q1营收+32.7%。为什么？

可能的解释：
1. **"口红效应"**：经济越差，企业主越焦虑，越想通过"上课"寻找出路
2. **马太效应**：中小企业培训预算收缩，但大客户预算稳定甚至增加，行动教育的大客户战略抓住了这一结构性变化
3. **幸存者偏差**：愿意付费培训的企业本身就是经营状况较好的，差的企业已经被淘汰出市场

### 5.2 宏观敏感度

李录在判断企业时特别关注"这个生意的命运取决于什么"。行动教育的命运在一定程度上取决于两个宏观变量：

| 宏观变量 | 影响机制 | 敏感度 |
|----------|---------|--------|
| **中小企业经营景气度** | 企业亏损面扩大→培训预算被砍→开课人数不足→收入下滑 | 高 |
| **结构性产业升级** | 传统产业衰退但新兴产业崛起→客户结构调整，需要新课 | 中 |
| **就业市场** | 失业率高企→更多人尝试创业→潜在客户增加 | 低（正相关） |

**历史压力测试**：2023-2025年是宏观环境较为严峻的三年，行动教育在这期间收入从6.7亿增至8.1亿（CAGR约10%），净利润从2.2亿增至3.2亿（CAGR约20%）。这说明公司确实有一定抗周期能力，但增速在放缓（2025年全年+3.55% vs 2026Q1+32.7%，波动较大）。

## 七、长期确定性：10年后行动教育会怎样？

### 7.1 10年后这个生意还在吗？

**大概率还在。** 企业管理培训是一个古老的需求——只要企业存在，企业家和管理者就需要学习如何更好地经营企业。需求端的确定性较高。

但"这个生意还在"不等于"行动教育还在"。关键问题是：行动教育能否在10年周期中持续创造价值？

### 7.2 AI是颠覆者还是赋能者？

这是一个需要诚实面对的问题。

**AI赋能的逻辑（公司叙事）**：
- AI可以帮助公司降本增效（AI营销、AI财务、AI教学）
- AI可以创造新的培训需求（《AI型组织》《AI决策》课程）
- AI可以帮助百校扩张（AI选人、育人、流程支持）

**AI颠覆的逻辑（需要警惕的）**：
- 如果AI最终证明它能替代"人类的决策判断和领导力培养"，那所有管理培训都会消失
- 李录的观点：AI可以替代知识传递，但很难替代"信任"、"情感连接"和"行为改变的动力"——这些都是线下深度培训的核心价值
- 但"很难"不等于"不可能"：培训智能体已经可以以1/10的价格提供部分替代效果

**判断**：未来10年，AI更可能是"重塑行业格局"而非"消灭行业需求"。行动教育的AI战略如果执行到位，可能成为加分项；如果处理不当，可能被AI-native的竞争对手超越。

### 7.3 什么可能真正颠覆行动教育的商业模式？

按威胁程度排序：

| 颠覆源 | 概率 | 影响程度 | 说明 |
|--------|------|---------|------|
| **预付费监管立法** | 高（3-5年内） | ★★★★ | 限额预收费+资金存管将根本改变现金流模型 |
| **李践退休/离职** | 低（5年内） | ★★★★★ | 公司过度依赖李践个人IP，一旦离开将面临"失去灵魂"的风险 |
| **AI替代知识传递型培训** | 中（5-10年） | ★★★ | 低端课程被替代，但核心高价值课程仍有需求 |
| **宏观经济长期萎缩** | 低 | ★★★★ | 若中小企业大规模萎缩，客户基础将崩塌 |
| **行业爆雷事件** | 中 | ★★★ | 若竞争对手出现"跑路"事件，监管收紧会波及全行业 |

### 7.4 长期确定性评分

| 维度 | 评分 | 说明 |
|------|------|------|
| 需求确定性 | ★★★★ | 企业培训需求长期存在 |
| 公司存续确定性 | ★★★ | 有生存能力但竞争格局可能变化 |
| AI影响 | ★★★ | 大概率成为赋能者，但有被颠覆风险 |
| 10年后可预见性 | ★★ | 人才依赖+监管不确定性使长期预测困难 |
| **综合** | **★★★（中等确定性，不是一个"10年后一定更好"的生意）** |

## 八、李录视角：综合判断

### 8.1 李录会怎么看待这个生意？

李录投资框架的核心是：**找到对的人、对的生意、对的价格**。他对行动教育的判断可能如下：

**管理层：李践是"对的人"但不是"最好的人"**

李践满足李录对管理层的部分标准：
- 长期主义（在同一领域深耕近20年）✓
- 与股东利益一致（高分红、0减持）✓
- 诚信度没有致命瑕疵 ✓
- 在能力圈内做出正确战略选择 ✓

但李践未满足的标准：
- 不是"一生中找到1-2个伟大想法并重仓投入"的那类人——百校计划是线性增长，而非指数级增长
- 93%分红率说明公司缺乏高回报的再投资机会，"利润再投资机器"的叙事不成立
- 公司的成功高度依赖李践个人的IP和精力，"离开创始人还能伟大"这一标准不满足

**生意：行动教育是一个"还不错"但不是"伟大"的生意**

李录判断一个生意是否伟大的标准包括：
- 10年后这个生意一定比现在更好？→ 不一定。预付费监管可能削弱现金流优势
- 这个生意有很宽的护城河？ → 有护城河（品牌+网络效应+预收款），但不是不可逾越
- 定价权？ → 有，但受客户支付能力制约
- 规模效应？ → 有，但在教育培训行业规模效应不如科技公司
- 客户转换成本？ → 低，客户可以轻易换培训机构

**确定性：行动教育属于"中等确定性"**

李录会将它归类为自己不会重仓的类型——不是因为它不好，而是因为"确定性不够高"。
- 10年后的样子不够清晰
- 对外部环境（监管、宏观、技术）的依赖度较高
- 对创始人的依赖度过高

但李录可能会欣赏这个生意的以下特质：
- 轻资产，不需要持续大量资本投入
- 预收款模式，现金流优秀
- 高毛利率+高净利率，盈利能力突出
- 高分红，给持有人提供了不错的持有回报

### 8.2 李录风格的关键追问

| 问题 | 回答 |
|------|------|
| **这个生意10年后还在吗？** | 大概率还在，但规模和盈利能力不确定 |
| **确定性从哪来？** | 来自中小企业持续存在的"想赚钱、想活得更好"的需求。这个需求不会消失 |
| **什么可能颠覆它？** | 预付费监管立法（3-5年内最高概率的风险）、李践的离开 |
| **李践是对的人吗？** | 在A股语境下是前20%的管理层，但在全球比较中是"B+"而非"A+" |
| **这个生意值得拥有10年吗？** | 作为组合的一部分（占5%-10%仓位）可以，但不应重仓 |

|------|-------------------|---------|------|

## 九、总体结论与评分汇总

### 9.1 各维度评分

| 竞争风险 | ★★ | 现有格局有利，线上替代需关注 |

### 9.2 核心结论

**行动教育是一个"可投但不应重仓"的标的。**

从李录视角看，它不满足"一生只需几次的正确决策"的标准：
1. **管理层的确定性不够**：李践61岁，对公司的依赖度过高。如果他在未来5-10年内退休，继任者能否延续公司的成功存在重大不确定性。
2. **生意的确定性不够**：预付费监管立法将从根本上改变公司的现金流模式，而这个风险的时间点和影响程度目前无法量化。
3. **长期增长的确定性不够**：百校计划是线性增长而非指数增长，AI战略尚未被证明能成为第二增长曲线。

**但它在以下方面是A股中稀缺的优质资产**：
- 真金白银分红（10.2亿 vs IPO 5.82亿）
- 78.86%毛利率、39.84%净利率、31% ROE
- 预收款模式带来的强现金流
- 管理层从未减持（仅关联平台减持）

**投资建议**：
- 作为价值组合中的"现金牛"配置（5%-8%仓位），享受高分红+稳健增长
- 不应重仓（>15%），因为确定性不够
- 核心监控指标：预付费立法进展、李践健康状况/退休计划、单校模型验证数据
