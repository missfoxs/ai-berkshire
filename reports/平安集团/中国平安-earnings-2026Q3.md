## 二、本期最重要的3个变化

### 1. 三份报表讲的是三个完全不同的故事——这是本报告的灵魂

这份三季报表面是"业绩暴雷"（净利润-27.3%、NBV-13.3%），但拆开看，三组数字指向三个结论：

| 指标 | 同比 | 真实含义 |
|------|:--:|------|
| 净利润 -27.3% | 🔴 | **市场给的**。Q3单季仅40.6亿（去年同期648亿，-93.7%），纯权益市场调整的投资端波动，无预测价值 |
| 营运利润 +8.3% | ✅ | **公司赚的**。与H1的+8.3%分毫不差，Q3单季+8.2%，真实经营能力纹丝不动 |
| NBV -13.3% | 🔴🔴 | **引擎熄火了**。连续两季负增长（Q2 -1.8%、Q3 -54%），这是唯一值得认真对待的真问题 |

**一句话：净利润暴跌别当真，营运利润稳如老狗，NBV才是需要盯的那个。**

### 2. NBV -13.3%：H1预警"Q3企稳"落空，连续两季负增长坐实

H1精读设的确认线是"Q3确认11%的增速是否企稳"。实际**-13.3%**，Q3单季更是**-54.1%**。这不是企稳，是加速下滑。

但必须客观拆解这-13.3%的构成（来自券商一致归因）：

| 原因 | 性质 | 权重判断 |
|------|------|:--:|
| 2025年8月预定利率下调前"抢购"高基数 | 一次性/节奏性 | 高 |
| 2026年6月银保渠道费用压降+精算假设调整 | 政策性/一次性 | 高 |
| 银保FYP环比-40%、代理人FYP环比-15% | 真实销售放缓 | 中 |

**关键判断**：这-13.3%里，大部分是"高基数+政策性"造成的，**不是竞争力崩塌**。2025Q3的133.89亿NBV本身是被"预定利率下调前的抢购潮"推高的异常值，今年的61.40亿是对那个异常值的回归。**但"销售放缓"这一项是真实的**——银保渠道首年保费环比-40%不可忽视。招银国际据此把全年NBV增速预期下调至**4.0%**（年初还在谈双位数）。

### 3. 产险COR 95.6%优化1.4pct——被寿险阴影盖住的真亮点

产险综合成本率从97.0%优化到95.6%，这是连续第N年改善。产险的承保纪律和风控能力是平安最"实"的资产之一，在寿险NBV熄火时，它提供了利润的稳定器。

同时，**非代理人渠道NBV占比36.9%（+1.8pct）**、**代理人渠道长交期占比+10pct**——渠道结构在变好，减少对代理人的单一依赖。这是改革的方向性正确。

**一个被忽略的结构变化**：营收-12.6%这个数字，主要是新会计准则（IFRS 17/9）下保险服务收入的口径调整，不是真实业务萎缩，看它会误判。保险股该看的是营运利润和NBV，不是这个"营业收入"。

1. **NBV连续两季负增长（Q2 -1.8%、Q3 -54%），2026全年NBV能否守住4%（招银口径）？分红险转型对价值率的冲击何时见底？**——这是决定"寿险改革红利"叙事存亡的问题
2. **利差损的量化测算**：近3年平均净投资收益率3.9%已跌破4%假设，管理层"无利差损"的表态，能否给出存量和新增利差损的绝对值？
3. **银保渠道在费用压降后的转型路径**：环比-40%的FYP是政策的一次性冲击，还是渠道模式的结构性失效？
4. **全年分红**：2026年全年每股股息能否维持2.70元（对应5.16%股息率）？这取决于全年营运利润，而非净利润。

## 六、与投资论文的关系

**原投资论文**（H1定稿）：中国平安是"低估值（P/EV 0.6x）+高股息+营运利润稳健+寿险改革NBV高增"的困境反转配置标的。

| 论文要素 | H1状态 | Q3后状态 | 变化 |
|------|:--:|:--:|:--:|
| 营运利润稳健 | +8.3% | +8.3%（分毫不差） | ✅ 强化 |
| 寿险NBV高增 | +11.2%（已从39.8%回落） | **-13.3%** | ❌ **破裂** |
| 低估值 | P/EV 0.60x | P/EV ~0.60x | ✅ 维持 |
| 高股息 | 中期+3.2% | 5.16%股息率 | ✅ 维持 |
| 地产出清 | 不动产3.1% | 维持 | ✅ 维持 |
| 医疗养老差异化 | 70% NBV来自服务权益客户 | 维持 | ✅ 维持 |
| 利差损可控 | 回避量化，近3年3.9% | 继续回避 | ⚠️ 未解决 |

**结论：论文被"削弱"，但没"破裂"。** 崩掉的是"NBV高增"这条成长叙事；但"低估值+高股息+营运利润稳健"这条防守逻辑，一根柱子都没倒。

## 七、结论：这份财报改变了什么？

### 1. 超预期 / 符合 / 低于预期？

**表面低于预期（净利润-27.3%、NBV-13.3%），实质符合预期（营运利润+8.3%）。**

市场会被净利润和NBV的两位数下滑吓到，但真正该看的营运利润+8.3%——它和H1分毫不差，说明平安的**真实经营能力没有因为一个季度的市场调整和监管变化而有任何动摇**。

### 2. 对投资论文的影响：**削弱**（从H1的"强化但有两道裂缝"降级）

核心变化是：**"寿险改革红利持续释放"这个成长叙事，在Q3被证伪了一半。** NBV连续两季负增长，招银把全年预期砍到4%。这不是"红利退坡"，是"红利阶段性耗尽+政策性逆风叠加"。

但反过来说，**0.60x P/EV + 5.16%股息率 + 营运利润+8.3%**，这个价格下，市场已经为"NBV熄火"和"利差损"打了足够的折扣。它不是成长股，但作为"高股息防守型配置"，逻辑依然成立。

### 3. 下一个催化剂

- **年报（2027年3月）**：全年NBV能否守住4%、利差损绝对值测算、全年分红、地产当期减值金额
- **利率走势**：10年国债若继续下行，利差损压力加大（近3年净投资收益率3.9%已跌破4%假设，这是最致命的慢变量）
- **权益市场**：净利润的波动全看它，但营运利润不看它——想赚"净利润弹性"的盯它，想赚"营运利润复利"的忽略它

### 4. 操作建议

| 状态 | 建议 |
|------|------|
| 已持有 | **持有，但降级预期**。从"困境反转成长"降为"高股息防守"。5.16%股息率+0.6x P/EV提供安全垫，但不是进攻品种 |
| 空仓 | **可作防守仓小配**，不要用"NBV高增"的逻辑买，要用"低估值+高股息"的逻辑买 |
| 加仓信号 | 全年NBV转正 / 利差损被证实可控（净投资收益率回升） / P/EV跌破0.55x |
| 减仓信号 | NBV连续三季负增长且销售放缓坐实 / 净投资收益率跌破3.5% / 分红下调 |

> **巴菲特**："保险这门生意，关键看浮存金的成本。平安的浮存金（6.49万亿保险资金）规模惊人，但成本取决于投资收益率能否覆盖负债成本——近3年3.9%的净投资收益率已经跌破了4%的精算假设，这才是需要盯的东西。至于净利润-27%，那是权益市场给的，和经营无关。"

> **段永平**："平安我看不懂，因为它太复杂——银行、保险、资管、科技、地产，每个都是精密的金融工程。但有一点是清楚的：看它不能看净利润，得看营运利润。营运利润+8.3%说明这公司还活着、还赚钱，但NBV-13.3%说明它'新来的钱'在变少。一个公司老业务还赚钱、新业务在萎缩，值多少钱？市场给的答案是0.6倍内含价值。"
