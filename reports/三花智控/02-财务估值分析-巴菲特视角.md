## 三、现金流分析（关键！）

| 指标(2024年) | 金额(亿元) | 备注 |
|:----:|:----:|:----:|
| 经营活动现金流净额 | 43.66 | OCF/净利润 = 1.24x ✅ |
| 购建固定资产支出（Capex） | 32.90 | **Capex/营收 = 11.8%** |
| **自由现金流（FCF）** | **10.76** | OCF - Capex |
| Capex/OCF | **75.3%** | 赚的钱75%要再投回去 |
| 每股自由现金流 | 0.26元 | |
| P/FCF | **138.9x** | 极高！ |

**巴菲特视角的核心警示**：

1. **经营现金流质量高**：OCF/净利润 = 1.24x，利润含金量没问题
2. **但Capex是黑洞**：32.9亿资本开支/43.66亿经营现金流 = **75%被"吃掉"**
3. **自由现金流极薄**：仅10.76亿，P/FCF = 139x——这意味着**按当前价格买入，要139年才能通过自由现金流收回投资**
4. **汽车业务需要持续烧钱**：热管理系统要在全球建产线（墨西哥、匈牙利、泰国等），未来3年Capex可能维持30亿+/年

> **巴菲特会说**："我喜欢那种把钱从工厂里拿出来、而不是不断往工厂里投的生意。三花赚的钱大部分要投回去建新厂——这更像是在'租赁'增长，而不是'拥有'增长。"

## 估值吸引力评分：★★☆☆☆（2/5）

**评分理由**：

三花智控是好公司（全球龙头、双轮驱动、管理层优秀），但**当前不是好价格**：

1. PE 35x + FCF Yield 0.72% + 股息率0.78% = **几乎没有安全边际**
2. 中性情景3年后目标价低于当前——即使业绩增长也可能不赚钱
3. 制造业公司给35x PE意味着市场把它当"科技成长股"估值，一旦增速不达预期就是双杀
4. 对比东鹏饮料（PE 18.8x + ROE 65% + FCF Yield 4.8%），三花的投资性价比极低

> **巴菲特的建议**："三花是好公司，但36元买一家ROE仅16%、FCF Yield不到1%的制造业公司——这不是'合理的价格买优秀的公司'，这是'昂贵的价格买不错的公司'。等到25元以下再考虑。"
