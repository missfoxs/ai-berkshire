## 核心结论

> 海天味业是A股最优质的调味品龙头——**业务质量满分但当前价格不便宜**。综合评分 **≈3.6/5**，**择时配置3-5%**——等待业绩拐点（增速回升至10%+）或股价回调（≤30元/PE 24x）信号。

## 投资建议

| 投资者类型 | 建议 | 仓位/价位 |
|-----------|------|----------|
| 激进型（追求成长） | 回避 | 不入场 |
| 稳健型（均衡配置） | 择时配置 | **建仓≤30元**（PE 24x） |
| 保守型（股息防御） | 配置 | 3-5% / 当前可入仓 |
| 套利型（AH折价） | 关注H股 | 折价32% |

**关键投资区间**：买入≤30元 / 持有30-36元 / 卖出≥42元

**关键催化剂**：
- **加仓**：股价回调至30元以下 / 季度营收恢复10%+ / 2026年报毛利率维持40%+ / 接班人计划正式公布
- **减仓**：季度营收连续2季<-5% / 毛利率跌破38% / 庞康完全退出董事会

## 核心争议

1. **PE历史最低≠绝对便宜**：PEG 2.91偏高，DCF显示按8%增速假设-9%高估
2. **渠道力是护城河还是包袱**：经销商从7430家降至3000-3500家；线上+31.87% vs 线下+7.85%
3. **接班人风险**：截至2026年9月，海天未发布任何正式"接班人计划"公告

## 四大师语录

> **巴菲特**："价格是你付出的，价值是你得到的。"——海天业务价值满分但当前价格已反映较多预期。
>
> **芒格**："好生意+好公司+好价格=好投资"——海天是前两项的优等生，但第三项需要等待。
>
> **段永平**："好的生意+合理的价格=好的投资"——海天的生意段永平会认可，但当前价格不便宜。
>
> **李录**："买股票就是买人"——海天的资本配置纪律是A股前5%，但接班人制度化是治理的最大盲点。
