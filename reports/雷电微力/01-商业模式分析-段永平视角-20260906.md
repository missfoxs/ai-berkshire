# 一、商业模式本质

## 1. 核心生意定义

**雷电微力为军工集团提供毫米波有源相控阵的关键射频前端和阵列天线，把GaAs/GaN等芯片、T/R组件、天线、封装、测试集成为可批量交付的微系统。**

更直白地说：

> 公司不是卖通用电子零件，而是按照军工客户的型号要求，研发、制造并交付高度定制化的"雷达/制导系统前端"。

客户付费的核心原因不是购买一颗芯片，而是购买以下综合能力：

1. 小型化；
2. 高频段工作能力；
3. 波束快速扫描能力；
4. 高可靠性；
5. 批量一致性；
6. 通过客户测试、验收和型号配套的能力。

但这类生意的关键弱点也很清楚：**收入确认取决于下游项目立项、批产、交付和验收，而非终端消费者的持续复购。**

### 结构变化的真正含义

表面上看，TR组件从2023年的边缘业务快速变成核心业务，意味着公司从阵列天线向更底层的组件延伸。

但不能简单把这种变化解释为"产品升级成功"，原因有三：

1. **2024年TR组件收入大增，但综合毛利率从2023年的52.16%降至41.62%**；
2. 2025年TR组件收入又下降至约2.85亿元；
3. 2025年公司整体收入下降37.23%，说明产品结构变化没有消除订单周期。

因此，更谨慎的判断是：

> 雷电微力完成了从单一阵列天线向"阵列天线+TR组件"的产品扩展，但目前尚未证明这种扩展已经带来稳定复购或更强定价权。

## 3. 价值链定位

```
上游：
GaAs/GaN射频芯片
陶瓷/有机基板
封装材料
射频连接器及测试设备
        ↓
中游：雷电微力
T/R组件
微波毫米波微系统
阵列天线
封装、组装、测试、交付
        ↓
下游：
军工集团、科研院所、通信设备客户
        ↓
终端：
精确制导、雷达、数据链、电子对抗、卫星通信等
```

### 价值链位置

雷电微力处于**芯片之下、整机之上**的中游高技术制造环节。

与铖昌科技、臻镭科技相比，公司更接近组件和微系统交付；与国博电子相比，公司的规模、国资背景和平台型能力相对弱一些，但在毫米波微系统和阵列天线集成方面具有自身定位。

公司并非传统意义上的芯片设计公司，也不是单纯代工厂。其核心价值在于：

- 射频前端架构设计；
- 芯片选型与匹配；
- T/R组件集成；
- 天线阵面设计；
- 热管理和封装；
- 批量制造与一致性控制；
- 配合客户完成系统级验证。

## 4. 商业模式类型判断

### 判断：设计制造一体化的定制化军工电子供应商

| 类型 | 是否符合 | 说明 |
|---|---|---|
| 纯芯片设计公司 | 否 | 公司主要收入来自组件、阵列天线和微系统 |
| 纯代工厂 | 否 | 公司参与产品设计、研发、封装、测试和交付 |
| 标准化零部件厂商 | 部分符合 | 产品有平台化基础，但型号配套高度定制 |
| 系统解决方案商 | 部分符合 | 能交付阵列天线和微系统，但通常不是完整雷达系统总包 |
| 设计制造一体化 | 是 | 研发、生产、测试、交付链条较完整 |
| 订阅/平台模式 | 否 | 收入以项目、批产和验收为主 |

这是一种**高研发、高认证、高定制、强项目制、弱复购可见性**的商业模式。

目前公开证据更接近后者。

# 二、产品飞轮与技术演进

## 1. 有源相控阵技术演进路径

### GaAs → GaN → 更高集成度的第三代半导体和异质集成

| 阶段 | 主要特点 | 商业意义 |
|---|---|---|
| GaAs | 技术成熟、频率性能较好 | 广泛用于传统微波射频前端 |
| GaN | 高功率密度、高效率、高耐压 | 适合高功率、高可靠雷达与通信 |
| GaN+先进封装 | 芯片、封装、散热协同优化 | 提升系统功率密度和可靠性 |
| SiGe、GaN-on-Si等路线 | 更重视成本、集成度和规模化 | 可能适合商业通信、车载等场景 |
| 异质集成/三维集成 | 射频、天线、功放和控制进一步融合 | 降低体积、重量和系统连接损耗 |

这里需要避免一个常见误区：**第三代半导体不意味着所有产品都会自动升级，也不代表GaAs会被迅速淘汰。**

不同频段、功率、成本和可靠性要求下，GaAs、GaN、硅基技术可能长期共存。

## 2. 从单一TR组件到系统级阵列天线

这条路径的战略意义有三层。

### 第一层：提高单个项目的价值量

单独交付T/R组件，客户仍需自行完成：

- 阵列布局；
- 天线设计；
- 热设计；
- 结构设计；
- 测试和校准；
- 系统联调。

如果公司可以交付阵列天线或微系统，就能承接更大价值量。

### 第二层：增加客户验证深度

单颗组件供应商容易被替换；阵列天线供应商一旦进入系统设计，切换会涉及：

- 重新设计；
- 重新测试；
- 重新进行环境试验；
- 重新进行型号鉴定；
- 重新验证系统性能。

因此，系统级交付可能提高转换成本。

### 第三层：但也增加交付和责任风险

系统级产品通常：

- 开发周期更长；
- 验收链条更复杂；
- 质量责任更重；
- 应收账款金额更大；
- 单个项目对收入影响更大。

2025年公司存货约10.5亿元，其中约64%为已发出商品，说明系统和项目制特点对资产负债表影响非常大。公司称上述存货均有订单支撑，但订单支撑不等于已经完成验收和回款。

## 3. 新场景与军用技术的协同性

### 卫星通信

协同点：

- 都需要高频段射频前端；
- 都需要波束赋形和快速扫描；
- 都重视小型化、低功耗和可靠性；
- 都可能使用相控阵天线和T/R组件。

差异点：

- 商业卫星对成本和批量要求更高；
- 军品客户对保密、可靠性和型号适配要求更高；
- 商业客户往往要求更快迭代和更低价格；
- 星载产品还面临抗辐照、重量和发射可靠性要求。

### 低空通航

可能应用于：

- 低空监视雷达；
- 通信链路；
- 无人机探测；
- 低空交通感知。

但低空市场的商业化仍取决于：

- 真实部署规模；
- 采购主体；
- 单站价值量；
- 价格下降速度；
- 监管和基础设施建设。

### 智能驾驶

汽车毫米波雷达确实与毫米波技术相关，但不等于军用相控阵产品可以直接转化为汽车产品。

汽车市场要求：

- 极低成本；
- 百万级规模；
- 高度标准化；
- 车规认证；
- 长期稳定供货；
- 快速迭代。

军用微系统的高可靠和定制能力可能是优势，但成本结构也可能成为劣势。

## 4. 公司是否在建立技术飞轮？

### 可能形成的飞轮

```
军用型号配套
    ↓
积累毫米波设计、封装、测试经验
    ↓
提升产品可靠性和批量制造能力
    ↓
进入更多军用型号
    ↓
开发卫星通信、低空等相邻场景
    ↓
扩大出货量，摊薄研发和制造成本
```

### 目前飞轮尚未被财务数据证明

如果技术飞轮已经运转，通常应看到以下至少几项：

1. 收入持续增长；
2. 新产品收入占比提高；
3. 毛利率不因扩品明显恶化；
4. 研发费用持续转化为订单；
5. 应收和存货增长低于收入增长；
6. 客户数量和项目数量扩大；
7. 经营现金流稳定。

雷电微力目前的实际数据是：

- 2024年收入11.80亿元，同比增长33.18%；
- 2025年收入7.40亿元，同比下降37.23%；
- 2025年归母净利润1.64亿元，同比下降52.04%；
- 2026年上半年收入6833.24万元，同比下降85.22%；
- 2026年上半年归母净利润亏损9148.77万元；
- 2025年研发投入6593.20万元，研发投入率8.90%，同比下降21.54%。

这说明公司具备技术积累，但**订单飞轮尚未表现为稳定的商业飞轮**。

### 段永平式追问

> 如果未来五年不新增"卫星通信""低空"等故事，仅靠现有军品业务，公司能否稳定增长？

公开数据暂时无法给出肯定答案。

# 三、护城河分析

| 护城河类型 | 强度 | 证据 | 反面证据 |
|---|---:|---|---|
| 技术壁垒 | ★★★★ | 毫米波T/R组件、阵列天线、微系统需要射频设计、封装、散热、测试协同；公司有长期研发积累及相关专利 | 公开资料无法验证关键型号的性能领先幅度、良率和技术领先年限 |
| 客户认证壁垒 | ★★★★ | 军工型号配套需要较长验证和定型周期，切换供应商会影响重新测试和交付 | 客户集中度高，客户拥有较强定价和验收权；认证壁垒也可能变成公司进入新客户的壁垒 |
| 规模效应 | ★★★ | 批量生产可摊薄研发、设备和测试成本 | 2025年收入大幅下降，规模效应不稳定；军品型号多、批量可能有限 |
| 转换成本 | ★★★★ | 进入整机/阵列设计后，替换需要重新设计、验证、测试和定型 | 如果公司仅作为组件供应商，客户仍可能引入第二供应商 |
| 网络效应 | ★ | 军工客户之间不存在典型用户网络效应 | 客户越多不会直接提升其他客户产品价值 |
| 品牌效应 | ★★ | 军工领域长期配套记录和质量声誉有价值 | 品牌影响力不能像消费品牌一样形成公开定价权，且订单仍受军方预算和型号节奏影响 |

## 护城河的核心判断

雷电微力最真实的护城河不是品牌，也不是网络效应，而是：

> **技术积累 + 型号认证 + 系统集成 + 交付可靠性。**

但这条护城河具有两个限制：

### 限制一：护城河保护的是"项目"，未必保护"公司整体收入"

某个型号进入批产后，公司可能受益多年；但如果型号数量少、订单间隔长，公司整体收入仍会剧烈波动。

### 限制二：护城河不等于定价权

军工客户通常具有：

- 集中采购能力；
- 审价机制；
- 较强的技术和质量话语权；
- 较长的付款周期。

2025年某批产项目审价调减当期收入约5300余万元，正是定价权不足的直接例子。

## 未来3—5年护城河趋势

| 情景 | 护城河变化 |
|---|---|
| 军品型号持续批产，阵列天线继续进入系统级配套 | 变宽 |
| 订单仍集中于少数项目，产品竞争转向价格 | 基本不变或变窄 |
| 商业卫星市场放量且公司能实现低成本量产 | 变宽 |
| 商业市场只停留在送样和小批量 | 不变，叙事大于业绩 |
| 国资背景竞争者扩大组件和微系统产能 | 相对变窄 |

## 巴菲特式追问

> 十年后客户仍然必须找雷电微力吗？还是只要有资金和技术团队，就能复制一个合格供应商？

公开信息支持"进入门槛较高"，但不足以证明"长期不可替代"。

# 四、客户价值与议价能力

## 1. 主要客户类型与集中度

主要客户包括大型军工集团及其下属单位，应用于：

- 精确制导；
- 雷达探测；
- 数据链；
- 电子对抗；
- 卫星通信。

公开资料显示公司采用直销模式，客户主要为大型军工集团。由于客户信息涉及保密，前五大客户的具体名称、销售金额及占比需要以完整年报附注为准；本次检索未获得可以可靠核对的2025年前五大客户完整表格，因此不对具体比例作无依据填充。

### 已知的集中度信号

2026年5月，公司签订某阵列天线产品订货合同，含税金额约4.43亿元，相当于2025年经审计营业收入的约59.8%。

这说明：

- 单笔合同可能对全年收入产生重大影响；
- 订单集中度高；
- 订单签署与收入确认之间仍有时间差；
- 不能把合同额直接等同于未来收入和利润。

**来源**：[四川在线：4.43亿元订单报道](https://cbgc.scol.com.cn/news/7622650)

## 2. 客户议价能力

### 客户较强的原因

1. 大型军工集团采购规模大；
2. 客户数量有限；
3. 客户掌握型号和系统集成标准；
4. 军品存在审价机制；
5. 客户可通过竞争性配套、二供体系压价；
6. 公司收入受客户验收进度控制。

### 公司相对有利的因素

1. 已进入型号配套的供应商切换成本较高；
2. 高可靠产品不能仅靠低价替代；
3. 产品质量问题会影响整机交付；
4. 如果公司掌握特定设计和工艺，客户不愿轻易更换。

### 结论

公司具备一定产品层面的议价能力，但尚未显示出持续提价权。

## 3. 收入确认：验收制对业绩的影响

军工电子产品通常涉及：

```
签订订单
→ 设计/研制
→ 生产
→ 交付
→ 客户测试
→ 验收
→ 收入确认
→ 回款
```

这会造成以下扭曲：

### 收入波动

订单可能已经签署，但只要尚未完成验收，就不能完全转化为当期收入。

2026年半年报显示，公司解释业绩下滑的原因包括：

- 行业订单波动；
- 项目验收滞后；
- 2024—2025年销售订单较少；
- 2026年新增订单因生产和验收周期较长，上半年完成交付验收的产品较少。

### 存货增加

已发出商品若尚未验收，可能仍在存货中。2025年末存货约10.5亿元，其中约64%为已发出商品。

### 应收账款增加

收入确认后，回款仍可能取决于客户结算和审价进度。2026年上半年公司计提信用减值损失约7741.66万元，资产减值损失约2570.89万元，合计超过1亿元。

核心判断：

> 2025年经营现金流转正是积极信号，但不能抵消"存货接近收入规模、已发出商品占比高、应收信用减值集中暴露"的风险。

# 六、风险与盲点

## 1. 2024—2025年订单断档：商业模式是否本就脆弱？

这是最重要的质疑。

2024年收入仍达到11.80亿元，但2024年四季度收入仅约790万元；2025年收入进一步下降至7.40亿元；2026年上半年收入仅6833万元。

这说明公司业绩高度依赖：

- 特定项目；
- 特定客户；
- 特定验收时间；
- 特定批产节奏。

### 多头解释

- 军工订单天然具有周期性；
- 2024—2025年可能是行业调整和验收滞后；
- 2026年已经签署4.43亿元大单；
- 经营现金流2025年转正；
- 公司具备技术和产品基础。

### 空头解释

- 订单断档可能不是偶发，而是公司缺少持续型号储备；
- 大订单不代表已经收入确认；
- 存货和应收的高风险已经通过减值体现；
- 如果客户集中度高，公司对下游议价能力弱；
- 2026H1亏损说明恢复尚未发生。

### 判断

目前不能把2024—2025年全部归因于周期。更稳妥的结论是：

> 公司具有明显周期属性，且周期波动已经大到足以改变盈利和现金流质量；在连续两个以上完整年度证明订单稳定前，不宜按稳定增长型公司估值。

## 2. 卫星通信能否成为第二增长曲线？

### 支持证据

1. 相控阵天线天然适用于卫星通信；
2. 公司具备毫米波微系统和阵列天线能力；
3. 卫星互联网需要高性能射频前端；
4. 同行业企业已经出现低轨卫星和商业航天批量交付案例；
5. 2026年公司提出拓展通用市场。

### 不足证据

1. 缺乏明确披露的卫星通信收入规模；
2. 缺乏连续年度收入增速；
3. 缺乏已确认的大客户和长期框架订单；
4. 缺乏商业卫星产品毛利率；
5. 缺乏量产交付和回款数据；
6. 军品技术无法自动转化为商业产品竞争力。

### 判断

卫星通信目前应定义为：

**潜在第二曲线，而不是已经成立的第二曲线。**

要确认其成立，至少需要看到：

- 连续两到三个季度收入增长；
- 商业客户数量增加；
- 产品从样品、小批量进入批量交付；
- 应收和存货增长不超过收入增长；
- 毛利率没有因价格竞争大幅下滑。

## 3. 与国资背景竞争者的竞争劣势

### 主要劣势

| 劣势 | 影响 |
|---|---|
| 客户与型号资源相对有限 | 新项目获取难度更高 |
| 资金实力弱于大型国企和军工电子平台 | 长周期研发承受力较弱 |
| 系统级协同能力较弱 | 可能在整机或大型型号中处于次级供应商位置 |
| 规模较小 | 单位成本和交付能力可能不占优 |
| 政策和供应链资源较少 | 在关键材料、产能和重大项目中可能受限 |
| 客户集中 | 单一客户变动影响更大 |

### 潜在优势

- 决策速度快；
- 专注毫米波微系统；
- 制造和组织更灵活；
- 在部分细分型号中可能形成快速响应优势；
- 民营机制可能更重视成本和交付效率。

结论不是"民营必输"，而是：

> 在军工行业，技术壁垒必须与型号资源、客户关系、交付能力和资本实力结合，单一技术优势未必足以转化为持续订单。

# 七、结论

## 3—5条核心结论

### 结论一：公司卖的是高门槛产品，但不是稳定复购型生意

雷电微力的核心能力是毫米波T/R组件、阵列天线和微系统的设计制造一体化，技术与认证壁垒真实存在。

但2025年收入下降37.23%，2026H1收入下降85.22%，说明收入仍强烈依赖项目批产和验收。

### 结论二：产品结构升级已发生，但尚未转化为稳定护城河

TR组件收入从2023年的约0.42%提升到2024年的49.48%，2025年约38.43%；阵列天线仍是主要收入来源。

产品线更加完整是积极变化，但2024—2025年毛利率下降、收入下降说明产品扩展没有消除订单周期，也没有证明定价权增强。

### 结论三：真正的护城河是型号认证和交付能力，不是品牌或网络效应

公司可能具备较高技术和客户认证壁垒，但公开资料无法确认：

- 关键型号的唯一性；
- 良率；
- 客户切换成本；
- 与竞争者的性能差距；
- 未来项目的持续性。

因此护城河评级为中等偏强，而非不可替代。

### 结论四：资产负债表暴露出项目制生意的代价

2025年存货约10.5亿元，约64%为已发出商品；2026H1信用减值损失约7741.66万元、资产减值损失约2570.89万元。

这表明"有订单"与"能验收、能回款、能产生现金"之间存在明显差距。

### 结论五：4.43亿元订单改善了预期，但不能直接等于业绩反转

4.43亿元订单约为2025年收入的59.8%，体量重要，但还要跟踪：

1. 实际交付时间；
2. 验收节奏；
3. 审价结果；
4. 毛利率；
5. 回款；
6. 后续订单是否连续。

单笔大订单不能替代可验证的复购飞轮。

## 段永平式一句话投资判断

> **这是一门"技术上不容易做、客户却未必容易伺候"的军工项目生意；在订单和回款被证明稳定之前，不能仅凭相控阵和卫星通信的好故事把它当作长期复利资产。**

当前商业模式建议：

**观望，等待订单兑现和现金流验证；不宜仅因4.43亿元订单或卫星通信叙事追高。**
