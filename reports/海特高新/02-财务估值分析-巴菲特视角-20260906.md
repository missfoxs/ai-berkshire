### 1.3 趋势解读（巴菲特视角）

1. 2021年归母3.43亿含**巨额非经常性损益7.36亿**（处置华新乙丑股权等），扣除后主业微利——表面繁荣实则脆弱
2. 2022-2024年扣非净利润CAGR约3.4%（0.38→0.41），**主业增速缓慢**
3. 2025年是结构性断裂点——减值打破所有趋势线

### 4.1 三大现金流趋势（2022-2025）

### 4.2 现金流画像解读

**2022年**：经营现金流强劲（4.78亿）+ 低资本开支（0.74亿）= 自由现金流4.04亿，**现金奶牛模式**

**2023年（关键拐点）**：经营现金流降至3.38亿 + 资本开支暴增至5.81亿（含4.7亿购飞机）= **自由现金流转负-2.43亿**。通过筹资2.62亿填补缺口。

**2024年**：经营现金流4.07亿 + 资本开支回落至1.10亿 + 处置华新乙丑股权流入1.17亿 = 自由现金流2.97亿

**2025年**：经营现金流**创历史新高5.84亿**（同比+43.50%）+ 资本开支1.27亿 = 自由现金流4.57亿

### 4.3 2025年经营现金流为何"逆势增长"？

销售回款增加4.18亿元，回款增速远高于营收增速（+43.50% vs +18.13%）—— **应收账款周转加速或前期账款集中收回**。

```
2025经营现金流/营收 = 5.84 / 15.59 = 37.46%
2024经营现金流/营收 = 4.07 / 13.19 = 30.86%
2023经营现金流/营收 = 3.38 / 10.53 = 32.10%
2022经营现金流/营收 = 4.78 / 9.10 = 52.53%
```

**反常信号**：2025年现金流/营收比率**回升至37%**，但**净利率崩塌至-37.81%**。**现金流入与会计利润严重背离** —— 这种背离在巴菲特看来需要警惕，可能源于：
1. 前期应收账款集中回收
2. 客户提前付款（如有一次性预收款）
3. 折旧摊销等非现金费用抵消

### 4.4 2026H1经营现金流转负分析

**直接原因**：①上年同期高基数（2.59亿）；②业务增长带动采购支出增加

**深层风险**：
- 应收账款较上年末增加17.34%
- 在建工程增加255.84%（新产能投入期）
- 长期借款增加29.25%（扩张依赖债务）

**巴菲特警告**：营收增长+现金流转负+借款增加 = **危险三角**。
